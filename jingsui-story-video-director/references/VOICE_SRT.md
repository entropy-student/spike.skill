# VOICE + SRT PROFILE V3.2

## 1. 实测速度

三条真实旁白：5.66 / 6.32 / 5.67 中文字/s；加权约 5.92。

默认初稿：5.9 字/s。

## 2. 时长反推字数

- 60s：340–370 字
- 90s：510–560 字
- 150s：850–920 字
- 180s：1020–1110 字
- 210s：1190–1300 字
- 240s：1360–1480 字

## 3. 口播节奏

特点：密、连续、少长空白。

工程停顿：
- 意群内部：0.08–0.18s
- 句间：0.15–0.30s
- 边说边修正：0.20–0.45s
- 段落转折：0.30–0.55s
- 中文最终落锤后：0.5–1.0s
- 英文尾签后：自然结束

## 4. SRT 拆法

字幕单位 ≠ 完整句。

默认 cue：
- 9–18 中文字；
- 1.4–3.2s；
- 最多两行；
- punchline 可以独立一 cue；
- 不拆固定搭配/人名/梗的核心词。

## 5. provisional SRT

无真实音频：
1. 按 5.9 字/s；
2. 加自然短停顿；
3. 中文落锤后留 0.5–1.0s；
4. 英文尾签独立 cue。

有最终配音：全部按真实音轨重新对齐。
