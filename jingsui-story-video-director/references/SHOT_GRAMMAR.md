# SHOT GRAMMAR V3.2 — 三视频校准

## 1. 三层视觉单位

L1 Scene/Layout：空间或整体构图变化。
L2 Visual Beat：姿势、表情、关系、物件、比喻含义变化。
L3 Micro Motion：汗滴、动作线、速度线、局部位移、简单循环。

不要把 L3 当成必须新生图。

## 2. 多视频实测中心

三条完整MP4，总时长约564.1s。

视觉变化工程检测：
- 样本A中位约2.67s，P25≈1.87s，P75≈3.20s；
- 样本B中位约2.73s，P25≈2.11s，P75≈3.48s；
- 样本C中位约2.77s，P25≈1.56s，P75≈4.01s。

因此默认使用：

```text
快反应/笑点      0.8–1.8s
普通叙事          2.0–3.4s
小场景/关系镜      2.5–4.2s
比喻/解释          2.8–4.8s
落锤/特殊镜        4.0–8.0s（必要时更长）
```

不要固定3秒切。

## 3. 主视觉类型

S1 白底人物状态
S2 人物动作演绎
S3 双人/多人关系
S4 最小生活场景
S5 物件特写
S6 荒诞联想/双关字面化
S7 群体/制度示意漫画
S8 标点型镜头：黑卡/强色/超大字/超大特写
S9 结尾落锤

## 4. 换图触发器

新人物 +2
新地点/关系 +3
新动作 +2
明显情绪变化 +2
新关键物件 +1
双关字面化 +3
荒诞类比 +3
群体/制度切换 +2
段落落锤 +2
仅补充解释 -2
同姿势同含义 -2

>=3：新 visual beat
1–2：同构图变体/L3
<=0：保持画面

## 5. 常用链条

### A 事实 → 反应 → 梗
事实发生 → 主角反应 → 旁白抛梗 → 梗字面化。

### B 事实 → 小场景 → 点评
最小场景交代事实 → 切主角表情 → 吐槽。

### C 现实 → 脑内夸张 → 回现实
这是核心漫画感来源。

### D 对比
别人状态 → 我状态 → 同构图夸张差异。

## 6. Visual Density Curve

- 0–15s：中高密度；
- 主故事：中密度；
- 连续梗：局部高密度；
- 观点提炼：中低；
- 最后10–18s：低密度。

不是“开头必须疯狂快切”，而是语义变化越密，visual beat 越密。

## 7. Punctuation Frames

用于：
- 强笑点；
- 段落换气；
- 情绪落锤；
- 结尾。

类型：黑底/强色底/超大人物/超大关键词。
工程默认 3–10%，不得发展成信息卡视频。

## 8. 防PPT

禁止连续：标题卡、数据卡、人物左+文字右、图标列表。
解释也尽量用人物、队列、物件、动作、荒诞构图。

## 9. 防生图浪费

visual beat 数量 ≠ 完全新构图数量。

工程目标：
- 65–75% beat 优先用既有资产变体；
- 15–25% 新关系/新小场景/新比喻；
- 5–10% 特殊重锤镜。

该比例是制作优化目标，不是参考视频精确统计。
