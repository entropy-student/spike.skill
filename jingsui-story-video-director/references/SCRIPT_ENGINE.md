# SCRIPT ENGINE V3.4 — 更接近真实口语叙述

## 1. 总原则

不要从“我要表达什么观点”开始写。
先问：
> 这个人最近到底碰到了什么具体事？他当时怎么想？事情后来又怎么发展？

默认结构：

> 签名 → 具体处境 → 生活证据 → 自嘲/梗链 → 事情继续 → 第二组证据 → 认知变化 → 回到自己 → 英文尾签

观点必须从事件里长出来。

## 2. 开篇

固定签名后，优先三种入口：

### E1 直接事件
`大家好，我是{{IP_NAME}}。前两天……`

### E2 本期故事
`大家好，我是{{IP_NAME}}。今天讲一下我……这件事。`

### E3 当前状态
`大家好，我是{{IP_NAME}}。最近有人问我……来跟大家交代一下。`

随后 1–3 句内给第一个反差/自嘲/离谱比喻。

## 3. 人称纪律

前半段尽量黏住具体人称：
`我 / 家人 / 朋友 / 同事 / 室友 / 领导 / 某个具体的人`

避免：
- 很多普通人的问题是……
- 现代人的通病是……
- 当代年轻人往往……
- 大多数人其实……

确需推广时，在事实充分后用：
- 我后来就会想，我们是不是……
- 你仔细想想……
- 我们这代人……
- 搞得大家……

## 4. 句法

优先连接：
`但 / 结果 / 另外 / 不过 / 其实 / 而且 / 比如 / 至于 / 可惜 / 好在`

降权：
`说白了 / 归根结底 / 真正的问题是 / 本质上 / 因此`

真实感来自长短混合，不来自句句短促：
- 中位句约 30 中文字符；
- 常规 18–45；
- 延展梗链允许 60–90。

## 5. 梗链

每篇优先设计 1–3 个“梗母题”，而不是 8 个孤立笑点。

一个梗链：
```text
现实事实
→ 荒诞比喻
→ 再推一步
→ 再推一步/词义变形
→ 回到现实
```

例：精力像工资
`月初到账 → 通勤扣一点 → 工作代扣 → 手机自动续费 → 最后余额不足`

梗链最好同时能产生 3–5 个连续分镜。

## 6. 自我修正

可用但不强制。通常 0–1 次。
只有前一句真的需要修订时才写：
- 这句话可能不太准确……
- 不过这么说也不完全对……

禁止为“像”而固定插入“不对，准确地说”。

## 7. 抽象主题落地

抽象词必须兑换成现实动作：
- 精力 → 起床、通勤、工作群、下班、睡觉、手机；
- 焦虑 → 半夜睡不着、反复看消息、脑内模拟；
- 边界 → 下班后回复、被临时叫走、拒绝一次饭局。

连续抽象名词不得超过 2 句。

## 8. 观点段

不要突然变“老师”。
优先：
`所以我现在…… / 这件事之后我…… / 我后来慢慢觉得……`

然后才允许：
`我有时候就会想，我们……`

## 9. 结尾

结尾三拍：
1. 回到“我”；
2. 用全文梗母题回扣一次；
3. 一句简单、略带翻译腔的英文。

英文不要润色成漂亮 slogan。


## 10. 具体人物优先（V3.4）

抽象主题优先寻找一个具体承载者：
- 一个朋友；
- 一个同事；
- 一个家人；
- 一次同行/出游/吃饭/加班/回家的具体经历。

先让观众“看到这个人”，再讨论这个人代表的现象。

不要：
> 我发现高精力人群往往……

优先：
> 我有个朋友，是我见过精力最旺盛的人之一……

如果题目本身就是单人独处事件，不强行添加配角。

## 11. Thesis Delay（观点后置）

150–240 秒稿件默认：
- 前 0–20%：人物/处境；
- 20–50%：事件、反应、梗链、第二证据；
- 50–70%：认知开始变化；
- 70–90%：观点展开；
- 90–100%：回到“我”并落尾。

不要在前 1/3 写出完整答案。

## 12. 梗母题预算

默认只允许 1–2 个主梗系统。

例如本期“精力”：
- 主母题：电池 / 漏电；
- 副母题：工资 / 扣款。

同一母题优先连续推进，而不是每段发明一个新比喻。

## 13. 结尾禁止变成攻略

结尾优先：
> 我最近真的做了什么小变化 → 这个变化也不完美 → 回扣全文母题 → 英文尾签

禁止：
> 从今天开始，你要做到第一……第二……第三……

## 14. 演讲腔黑名单

降权：
- 很多普通人的问题是
- 现代人的通病是
- 大多数人其实
- 真正的问题是
- 归根结底
- 第一步不是……而是……
- 你需要的是

如果删掉这些句式后含义仍成立，直接删掉。
