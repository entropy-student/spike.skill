# Jingsui Story Video Director

A calibrated workflow for first-person story-driven comic videos: topic → spoken script → SRT → visual beats → storyboard → image-generation plan → edit plan.

## Status

**v3.4.0 / Calibrating**

The skill is derived from multiple real audio/video samples at the level of narrative structure, pacing, humor mechanisms, visual semantics, and production engineering. Production output must use an original IP and must not copy the reference creator's character, wording, jokes, or existing shots.

## V3.4 focus

- concrete person/event before abstract thesis;
- thesis delayed to roughly the second half;
- 1–2 recurring humor metaphors instead of scattered one-off jokes;
- no generic lecture phrasing;
- ending returns to the narrator instead of becoming a checklist;
- lightly literal English sign-off is allowed.

See `SKILL.md` for execution rules.
