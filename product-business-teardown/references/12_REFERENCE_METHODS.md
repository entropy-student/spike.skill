# Reference Methods Used

本 Skill 不是任何单一框架的复制，参考并重新组合了以下思想：

- Jobs-to-be-Done：从用户要取得的进展而非功能出发；真实竞争包括替代与 non-consumption。
- Business Model Canvas：Customer Segments / Value Proposition / Channels / Revenue / Cost 等基本商业结构。
- Value Proposition：Who / Why / Before / How / After / Alternatives。
- Value Chain / Activity System：从活动、成本、差异化、链接和 fit 解释价值如何产生。
- Value Stick：WTP / Price / Cost / WTS，用来解释价值创造和价值捕获。
- Profit Pools：行业收入分布与利润分布可能不同，寻找真正的利润集中环节。
- Monetizing Innovation / pricing：谁付款、为哪种价值付款、收费指标如何跟价值同步。
- Platform Strategy：多边平台要分析参与者、匹配、信任、流动性与网络效应，而非强行套线性链条。

这些方法只作为底层工具；实际拆解必须根据产品类型路由。
