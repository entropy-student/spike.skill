# Reference Methods

本 Skill 借鉴但不机械复制以下方法：

- Jobs to Be Done：先理解用户要取得的进展，以及所有真实替代方案；
- Value Proposition：Who / Why / Before / How / After / Alternatives；
- Business Model Canvas：Create / Deliver / Capture Value；
- Value Stick：WTP / Price / Cost / WTS；
- Profit Pools：收入集中与利润集中可能不同；
- Value Chain / Activity System：优势来自活动及其相互配合，不只是供应链图；
- Platform Strategy：多边参与者、匹配、信任、流动性与网络效应；
- Monetization / Packaging：付款边界、收费单位、免费→付费、cross-subsidy；
- Competitive Positioning / Teardown：公开证据驱动的替代、定位、差异与可防御性。

这些方法是组件，不是固定答案。分析结构必须服从具体产品类型、分析单位与证据丰富度。
