# Research Source Strategy

## 已有产品
至少覆盖三种证据类型：
1. 官方/财务；
2. 用户/交易/评论；
3. 竞争/渠道/运营代理信号。

## 关键优先来源
Pricing / Terms / Help / Docs、Annual report / 10-K / investor relations、App stores / marketplaces、customer case studies、partner/developer documentation、public interviews、job postings、reputable industry research、Reddit / forums / social。

## 搜索问题示例
- `[product] pricing`
- `[company] annual report revenue segment`
- `[product] customers use cases`
- `[product] alternatives reddit`
- `[product] review complaints`
- `[company] partner program`
- `[product] API developer`
- `[company] gross margin segment`

不要为了来源很多而重复使用同一个原始事件的二手转载。
