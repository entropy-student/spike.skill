# Source Strategy

真实产品分析优先级：

1. 官方产品页 / Pricing / Help / Developer docs；
2. 财报、10-K/20-F、投资者材料、监管披露（公司/产品线适用时）；
3. 官方客户案例、公开采访、合作伙伴/渠道信息；
4. App Store / Amazon / Etsy / Marketplace Listing 与 Reviews；
5. 高质量第三方行业研究；
6. Reddit / 社媒 / 社区：用于用户语言、痛点、替代行为和反证，不单独证明营收/利润。

## Sparse Evidence Rule
小商品或单一 SKU 不要求存在上市公司财报。若只有 Listing / Review / 图片：
- 可以判断使用场景、产品机制、价格、替代、渠道和可能成本栈；
- 卖家收入、毛利、CAC、净利润如果没有直接证据，必须写 UNKNOWN；
- 不因证据稀疏而停止，只降低结论强度。

所有具体数字记录时间与市场口径。不同年份、国家、渠道数字不得无说明混用。
