# Value Architecture

## Create
哪些输入经过哪些活动变成更有价值的东西？

## Deliver
价值通过什么渠道、界面、物流、服务、API、社区或匹配机制到达受益者？

## Capture
企业如何从创造的价值中拿走一部分？

## 常见价值机制
- 聚合：把分散供给集中。
- 搜索：降低发现成本。
- 匹配：找到合适交易对象。
- 协调：降低多方协作成本。
- 自动化：降低时间/人工。
- 标准化：降低复杂度与错误。
- 风险承担：退款、保险、担保、合规。
- 信任：评价、验证、品牌、认证。
- 推荐：提高选择质量。
- 个性化：提高相关性。
- 身份/品牌：创造社会与情绪价值。
- 体验设计：把复杂流程变简单。
