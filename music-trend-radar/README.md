# 🎵 Music Trend Radar（音乐趋势雷达）

### 跨平台热歌雷达 · Trending Music Skill

不只是抄三个音乐榜单，而是区分：**现在最热、正在爆发、新歌观察、平台偏科、稳定霸榜**，并给每首重点歌曲标记 **S+ / S / A / B** 趋势等级。

S+ 进一步区分 **active / culture / legacy**：当前爆发、文化持续扩散、以及已经沉淀为长期文化资产。

## 为什么做它？

单个平台榜单只能告诉你“这个平台现在排第几”。Music Trend Radar 想回答的是：

> 今天真正跨平台热门的歌是谁？
> 哪些歌正在明显变热？
> 哪些只是某个平台特别喜欢？

## 首批平台

- 网易云音乐
- QQ 音乐
- 汽水音乐

## 校准模式

前 3–7 轮固定输出：

- **Run A — Current Heat**：当前最热
- **Run B — Breakout**：正在爆发
- **Run C — Balanced Radar**：综合判断

这样可以直接和三个 App 的实际榜单对照，逐轮调整。

## 趋势等级

- **B**：已有真实热度，值得观察。
- **A**：强势热门 / 明显爆发。
- **S**：跨平台破圈爆款。
- **S+**：现象级传播模板，出现手势舞、挑战、翻唱、BGM 模板、梗化二创等持续增殖。

等级不等于榜单名次：一首歌可以“综合榜 #15，但 A 级”，也可能“单平台 #1，但还不足 S”。

## 最重要的原则

> 抓不到就写抓不到；没有历史就不编涨跌；汽水发现页不冒充正式热榜。

详细规则见 `SKILL.md`。

## B站校准

B站不作为第四个音乐榜，而是独立的二创传播维度。重点看最近7/30天新投稿、多创作者、多二创形态，以及歌曲是否从“被听”升级为“被拿来继续创作”。
