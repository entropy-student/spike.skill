# Tiering — S+/S/A/B Trend Level

等级描述歌曲当前的传播阶段，不等于任何平台官方排名。

## B — 有热度 / 值得观察

满足之一：
- 至少一个音乐平台 Top 50；
- 明确飙升/新歌榜高位；
- ShortVideoSocial >= 40；
- BiliBreakout >= 40。

## A — 强势热门 / 明显爆发

满足至少一类强证据：
- 至少 2 个音乐平台有榜单证据，且一个 Top 20；
- 单音乐平台直接榜单 Top 5，可标记为 `A (platform-led)`，避免平台冠军被错误降成 B；
- 单音乐平台 Top 10 + ShortVideoSocial >= 60 或 BiliBreakout >= 60；
- 连续快照显著上涨并跨平台同步；
- BiliBreakout >= 70 且至少有一个音乐平台直接榜单证据。

Confidence 不得为 Low。

## S — 全民爆款 / 破圈歌曲

允许两条进入路径：

### Music-consensus S（音乐平台共识）

必须满足：
1. 至少 2 个音乐平台直接榜单证据；
2. 两个平台都进入 Top 20，且至少一个进入 Top 10；
3. Confidence = High。

这一路径允许“音乐平台已经形成全民共识，但短视频/B站尚未模板化”的歌曲进入 S。

### Breakout S（传播破圈）

必须满足：
1. 至少 2 个音乐平台直接榜单证据；
2. 至少一个平台 Top 20；
3. `ShortVideoSocial >= 50` 或 `BiliBreakout >= 60`，或第三音乐平台也有明确高热；
4. Confidence = High。

第一次历史不足、证据边界不足时可标 `S候选`。

## S+ — 现象级 / 文化模板

### Active S+
先满足 S，再满足：
- `ShortVideoSocial >= 80` 或 `BiliBreakout >= 80`；
- 至少两种可复制衍生形态（手势舞、挑战、翻唱、剧情BGM、Remix、鬼畜、虚拟歌手等）；
- 至少两个非同源创作者/圈层持续接力；
- 最近 7 天仍有活跃证据，或短期出现强爆发。

### Culture-persistence S+（文化持续型例外）

允许歌曲在音乐榜名次回落后仍保持 S+，但必须同时满足：

1. 有历史证据证明它此前已完成多平台音乐爆发；
2. 当前 `ShortVideoSocial >= 80` 或 `BiliBreakout >= 80`；
3. 最近 7 天仍出现新的挑战/二创/明星或高传播投稿；
4. 可复制模板仍在扩散，而不是只有旧视频累积播放。

这种情况标记 `S+ (culture)`，防止《音乐榜回落但手势舞二次爆发》被错误降成 B/A。

### Legacy S+（历史文化资产）

用于已经完成主要爆发周期、当前 7 天不一定仍高频活跃，但已经成为长期可复用网络文化模板的歌曲/BGM。

必须同时满足：

1. 历史上明确达到过 S+（多平台音乐爆发 + 大规模衍生传播）；
2. 已经脱离原始歌曲语境，被长期当作固定 BGM、梗、挑战或表达模板使用；
3. 至少经历过一次跨月/跨季复活，或持续存在于不同圈层内容中；
4. 当前热度不足以称为 Active / Culture 时，才使用 `S+ (legacy)`，不能拿历史荣誉冒充“今日爆发”。

三种 S+ 的区别：

- `S+ (active)`：音乐榜与社交/B站都在当前强爆发；
- `S+ (culture)`：音乐榜回落，但最近 7 天文化模板仍在明显扩散；
- `S+ (legacy)`：当前不一定爆，但已经沉淀为长期文化资产。

## Bili Breakout 的硬约束

- 单个百万播放音乐搬运 ≠ Bili 80；
- 同一 UP 主几十条合集 ≠ 多创作者扩散；
- 最近 7 天新投稿 + 多创作者 + 多二创形态，才是高等级关键；
- 搜索结果只用于发现样本，最终结论尽量引用具体投稿/页面证据。

## 等级与名次允许不一致

- 综合 #15，Tier A：音乐榜一般，但 B 站/短视频迅速增殖；
- 综合 #3，Tier A：音乐平台高，但尚未破圈；
- 综合 #1，Tier S：全民热，但没有模板化二创；
- 综合 #12，Tier S+ (culture)：音乐榜回落，但挑战/手势舞仍在扩散。
