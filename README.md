`spike.skill` 是一个面向个人工作流的 **AI Skill Library**。

这里保存的不是一次性答案，也不是提示词收藏夹，而是那些已经经过真实使用和反复校准、值得长期复用的：

- 判断框架
- 提示词系统
- 评分规则
- 研究流程
- 工作方法
- 可交接执行标准

> **把一次有效的思考，变成以后随时都能调用的能力。**

## 🧩 一个方法什么时候值得变成 Skill？

最好至少满足其中几项：

1. **不是一次性答案** — 以后还会遇到同类问题。
2. **已经经过校准** — 有例子、反例和反馈修正。
3. **另一只 AI 也能执行** — 不依赖当前聊天上下文才能成立。
4. **输入输出明确** — 知道什么时候调用，也知道应该产出什么。
5. **能持续进化** — 新案例出现后是更新 Skill，而不是推倒重来。
