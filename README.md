## 🎯 [Entertainment Rander](./entertainment-rander/)

> 中文互联网娱乐热梗筛选与分级系统：不追热搜，专门判断哪些梗只是“大家会说”，哪些已经变成“大家会继续往下编”的梗宇宙。

**核心评级：** `S+` · `S` · `A` · `B`

### 一句话判断

> **B：大家会说 · A：大家会模仿 · S：大家会继续编 · S+：大家会拿它创造下一代梗。**
