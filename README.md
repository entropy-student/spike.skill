`spike.skill` 是一个个人 **AI Skill Library**。

这里不保存一次性答案，也不把零散提示词堆成收藏夹。它专门沉淀那些已经经过真实案例、反例和反馈反复校准，值得长期复用的方法：

- 判断框架与评分规则
- Prompt / Skill 规范
- 研究与筛选流程
- 可复现的输出结构
- 可交给另一个 AI 直接执行的工作标准

> **目标：把“这次想明白了”升级成“以后不用从头再想”。**

## 🧩 什么样的方法值得成为 Skill？

1. **会重复遇到**：不是一次性问题。
2. **已经校准**：有正例、反例和边界案例，而不是凭感觉写规则。
3. **可以交接**：换一个 AI，也能读懂并执行。
4. **输入输出明确**：知道什么时候调用、应该产出什么。
5. **能够迭代**：新案例出现时更新规则，而不是推倒重来。

---

## 🚀 Philosophy

最终想积累的不是一堆答案，而是一套越来越成熟的 **个人 AI 方法论资产**。

复杂判断不必每次从零开始；已经验证过的能力，应当可以像函数一样再次调用。
