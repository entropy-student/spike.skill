`spike.skill` 是一个面向个人工作流的 **AI Skill Library**。

这里沉淀的不是一次性答案，也不是简单的提示词收藏，而是那些已经在真实使用中被反复校准、可以稳定复用的：

- 判断框架
- 提示词系统
- 评分规则
- 工作方法
- 研究流程
- 可交接的执行标准

目标很简单：

> **把一次有效的思考，变成以后随时都能调用的能力。**

每一个 Skill 都尽量做到：**目标清楚、规则可执行、结果可复现、文档可继承、结构可扩展。**

## 🌟 Current Skill

## 🎯 [Entertainment Rander](./entertainment-rander/)

> 一个用于筛选和分级 **中文互联网娱乐热梗** 的 AI Skill。
>
> 它不追逐表层热搜，而是专门识别：哪些内容只是“热了一下”，哪些已经真正变成了大众会反复玩、模仿、考古、二创、继续往下编的 **梗宇宙**。

### 它特别适合

- 做 **今日 / 本周娱乐热梗雷达**
- 筛选适合图文、视频、封面的流行文化选题
- 判断某个梗到底属于 **S+ / S / A / B** 哪一档
- 给内容创作建立一套更稳定的“网感判断系统”
- 回顾历史热梗，区分“当时很热”和“真正留下来了”

**核心评级：** `S+` · `S` · `A` · `B`

![Entertainment Rander](./entertainment-rander/assets/entertainment-radar.jpg)

### 一句话记住它

> **B：大家会说 · A：大家会模仿 · S：大家会继续编 · S+：大家会拿它创造下一代梗。**

## 🧩 What makes a Skill worth keeping?

一个方法进入这个仓库前，最好至少满足其中几项：

1. **不是一次性答案**：以后还会遇到类似问题。
2. **已经经过校准**：规则不是拍脑袋，而是经过例子、反例和反馈修正。
3. **能交给另一只 AI 使用**：不依赖当前上下文才能成立。
4. **有明确输入和输出**：知道什么时候调用，也知道应该产出什么。
5. **有可继续进化的空间**：随着新案例出现，可以更新 Skill，而不是推倒重来。

## 🚀 Philosophy

我希望这个仓库逐渐变成一个自己的 **AI 技能图书馆**。

遇到复杂判断时，不必每次从零开始；遇到已经验证过的方法，可以直接调用；新的经验如果足够稳定，就继续沉淀成下一个 Skill。

最终想留下的不是一堆答案，而是一套越来越成熟的 **个人 AI 方法论资产**。
