# Creator Sponsorship Cold Start（自媒体品牌商单冷启动）

## 目标与范围

帮助用户回答：**从 0 开始，哪种自媒体账号模型最有可能持续获得品牌在该账号上的付费内容合作？**

账号模型不等于赛道名称。它由目标受众、持续需求、内容承诺、可重复的内容系列、品牌适配、平台条件和可持续制作方式共同组成。

本 Skill 只把品牌为创作者自有账号上的付费内容或发布位付费，计入核心广告收入。平台广告分成、联盟佣金、赠品、纯 UGC/素材制作费、自有产品收入可以单独记录，但不能替代品牌商单证据。

目标是比较并验证候选模型，不保证收入，也不因行业热度、粉丝量或单条爆款直接推荐赛道。

## 工作流程

### 1. 明确研究条件

确认或说明假设：目标平台与地区、语言、起号者的技能和资源、可投入时间与成本、期望验证周期，以及用户已有的赛道或账号约束。缺少的信息会实质改变结果时，先向用户询问。

平台准入、商业工具和披露规则会变化。执行时查阅当前官方规则，并注明市场、平台、核验日期和来源；不要把一次查到的门槛写成通用常数。

### 2. 写出可比较的候选账号模型

每个候选至少说明：

- **受众与持续需求：**谁会持续关注，解决或满足什么需求；
- **内容承诺：**观众为什么回来；
- **内容系列：**可重复制作的 2–3 种内容形式；
- **品牌适配：**哪些品牌会买什么价值，广告如何自然进入内容；
- **起号可行性：**从 0 如何获得受众信号，需要什么技能、成本、频率和平台条件；
- **主要风险：**受众规模或购买意图不足、内容容易同质化、品牌池集中、制作负担、平台依赖等。

不要只比较“美妆、科技、户外”等赛道标签。候选数量由证据决定，不必凑足固定数量。

### 3. 先验证品牌需求与小号可达性

回答两个不同的问题：

1. 该品牌类别是否持续为 Creator 内容投入预算？
2. 与新号起步路径相近的小中型账号，是否真实获得过**自有账号发布型**付费合作？

组合使用近期品牌 Campaign、平台招募或 Marketplace、真实创作者主页及其他可核验资料。行业报告可提供假设，不能代替真实账号样本。头部账号只能说明成熟形态，不能单独证明新号可进入。

### 4. 抽样真实账号并记录反例

采用适合具体平台和市场的抽样量，不预设固定账号数。结合广告主侧反查和赛道内系统抽样；条件允许时再加入平台招募样本。纳入没有明显商单的账号，记录抽样来源、观察区间和缺失数据。

明确区分 `PAID_ON_ACCOUNT`、`GIFTED`、`AFFILIATE_ONLY`、`UGC_ONLY` 和 `UNKNOWN`。核心统计只计可确认的自有账号付费合作；可疑样本另做敏感性分析，不把赠品或猜测算成收入。

控制幸存者偏差、平台推荐偏差、商业披露差异、季节性和地区差异。无法区分自然流量与付费放大时，将自然广告表现记为 `UNKNOWN`，不要直接比较总播放量。

### 5. 比较模型的收入潜力和可持续性

先排除明显不成立的条件，再对剩余模型作有证据的相对比较。至少检查：

- 品牌需求、品牌类别宽度和预算/采购频率；
- 小中型创作者进入付费合作的证据；
- 受众价值、自然内容中位表现和广告内容的原生适配；
- 跨品牌复投迹象、品牌集中度和合作节奏；
- 内容制作成本、时间、广告履约成本与净收入潜力；
- 平台依赖、商业合规与受众流失风险。

没有真实收入数据时，不推算精确报价、月收入或 ROI。只有当不同模型的口径相同时才排名；否则列出证据缺口，不用一个总分掩盖差异。

### 6. 设计最小双通道验证

**受众通道：**围绕少量内容系列做小规模发布，观察目标受众是否出现重复的正向信号、表现中位数是否可接受、制作能否持续。单条爆款不算通过。

**品牌通道：**选择与模型匹配的品牌和采购入口，测试具体内容提案是否带来合格需求、预算明确的 Brief、付费合作或复投信号。记录触达分母、回应质量和拒绝原因；没有回复只代表信号不足，不能单独判定模型失败。

可以在账号还小的时候验证品牌兴趣，但要把询盘、入选、赠品、UGC 订单和自有账号付费合作分别记录。Buyer Readiness 的可修复缺口作为执行问题记录，不要误判成赛道本身没有需求。

开始测试前，按用户的资源和周期写清继续、调整、停止的条件；不要将固定样本数或任意转化率当作普适门槛。

### 7. 分级表达结论

- **方向假设：**有市场或平台层面的信号，尚无足够真实账号证据。
- **候选模型：**真实中小账号和品牌需求支持进一步测试，仍未证明用户自己的起号能力。
- **初步验证：**用户自己的内容获得目标受众信号，并出现自有账号上的真实付费品牌合作。
- **可持续性证据：**跨时间有可重复合作或明确采购节奏，来自不止一个独立品牌，扣除制作与履约成本仍值得继续，且广告没有持续破坏受众价值。

说明已证明、未证明、置信度、主要偏差、关键风险和下一项最便宜的验证。若证据不足，明确写 `PROVISIONAL`，不把推断表述为事实。

## 默认交付

按候选模型给出：

1. 账号模型与目标受众；
2. 主要品牌类别、广告价值和小号采购证据；
3. 对照样本、观察口径和来源；
4. 自然内容、品牌商单、复投和制作经济性的证据；
5. 排序或暂不排序的理由、置信度与反证；
6. 最小受众实验、最小品牌验证和预先设定的停止条件。
