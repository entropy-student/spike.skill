# Creator Sponsorship Cold Start

本 Skill 用于从 0 发现并验证更可能持续获得**自有账号品牌商单**的自媒体账号模型。

核心收入只计品牌为创作者账号上的付费内容或发布位付费。平台广告分成、联盟佣金、赠品和纯 UGC 制作费分别记录，不作为品牌商单验证。

## 使用流程

先读 [SKILL.md](SKILL.md) 的目标和工作流程；进行真实账号研究时按需读 [抽样与模型比较](references/01_REAL_ACCOUNT_RESEARCH_AND_SCORING.md)。品牌难以发现或评估创作者时参考 [Buyer Readiness](references/02_BUYER_SIDE_COMMERCIAL_READINESS.md)；出现真实合作后再看 [Deal 与测量](references/03_DEAL_AND_MEASUREMENT_ARCHITECTURE.md)。准备冷启动实验时使用 [双通道验证](references/04_COLD_START_VALIDATION.md)，样本和决策可记入 [研究矩阵](templates/account-model-research-matrix.md)。

不把行业报告、平台门槛、单条爆款、头部达人或单次商单当作可持续收入的证明。动态的平台规则和采购入口须在每次研究时重新核验。
