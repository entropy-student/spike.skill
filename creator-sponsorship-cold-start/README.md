# Creator Sponsorship Cold Start

> **系统发现并验证：从 0 开始，哪些自媒体账号模型最有可能形成可持续的品牌商单收入。**

核心只看包含 Creator 自有账号付费发布的品牌合作；平台分成、联盟、赠品和纯 UGC-only 单独记录。

## 核心流程

~~~text
DEFINE BOUNDARY
→ OPEN-WORLD DISCOVERY
→ BUILD ACCOUNT MODELS
→ VALIDATE SPONSOR MARKET
→ TEST SUSTAINABILITY
→ APPLY USER FIT
→ SELECT CANDIDATES
→ DUAL VALIDATION
→ REAL PAID SPONSORSHIP
→ REPEAT / SCALE
~~~
