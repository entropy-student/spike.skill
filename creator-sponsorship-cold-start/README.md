# Creator Sponsorship Cold Start

本 Skill 用于：

> **从 0 系统发现并验证，哪些自媒体 Account Model 最有可能形成可持续的品牌商单收入。**

核心收入只计包含 Creator 自有账号付费发布的 Sponsored Account Contract；平台广告分成、联盟佣金、赠品和纯 UGC-only 收入分别记录，不替代账号商单验证。

## v0.4 核心流程

~~~text
DEFINE OBJECTIVE
→ OPEN-WORLD DISCOVERY
→ BUILD ACCOUNT MODELS
→ VALIDATE BRAND DEMAND
→ VALIDATE SMALL-CREATOR ACCESS
→ TEST SPONSOR FIT
→ TEST SUSTAINABILITY
→ APPLY USER CONSTRAINTS
→ SELECT CANDIDATES
→ COLD-START VALIDATION
→ REAL PAID SPONSORSHIP
→ REPEAT / SCALE
~~~

最大的原则变化：

- 不先凭印象推荐赛道；
- 不先用个人偏好砍掉市场搜索空间；
- Brand Breadth 不再等于“越宽越好”，改看 Addressable Sponsor Market；
- Content–Brand Fit 与 Audience–Brand Fit 分开；
- 小号能接广告与长期收入 Scale 分开；
- Sponsor Density 不假设越低越好，改看 Sponsor Capacity；
- 公开商单数据按 Lower Bound + Sensitivity Range 表达；
- Buyer Readiness 是执行层，不是市场本身。
