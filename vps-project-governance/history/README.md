# Governance history

Everything under this directory is historical and non-authoritative.

Current active Governance is always declared by `../SKILL.md`, `../metadata.yml`, and the root `../VNEXT.md`.

- `incidents/`: concise concrete incident records requested for durable Governance-side history or useful for recurrence/audit. Default Reviewer loading: **NO**.
- `vnext/`: exact historical `VNEXT.md` versions, one file per version in the same directory.
- `v0.2.0-refactor/`: original refactor/audit materials that produced the v0.2 line.
- `v0.1.6/`: complete legacy multi-file package retained for audit and rollback.

Historical records explain **what happened** or preserve an old rule version. They do not create policy. Current policy and standard problem-solving paths live only in the active `../VNEXT.md`.
