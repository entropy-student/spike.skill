# Governance history

Everything under this directory is historical and non-authoritative.

Current active Governance is always declared by `../SKILL.md` and `../metadata.yml`.

- `incidents/`: concise concrete incident records requested for durable Governance-side history or useful for recurrence/audit. Default Reviewer loading: **NO**.
- `v0.2.1/`: exact previous operational rule file retained for rollback.
- `v0.2.0/`: earlier operational rule file retained for rollback.
- `v0.2.0-refactor/`: original refactor/audit materials that produced v0.2.0.
- `v0.1.6/`: complete older active package retained for audit and rollback.

Historical records explain **what happened**. They do not create policy. Current policy and standard problem-solving paths live only in the active `VNEXT.md`.
