# Xianyu & Xiaohongshu Virtual Product Opportunity

面向 **闲鱼 / 小红书虚拟产品** 的机会发现与筛选 Skill。

它不是“资料包爆款榜”，而是把平台信号拆成：

> **真实问题 → 真实付费 → 平台可触达需求 → 竞争结构 → 产品差异化 → 分发适配 → 信任与 Proof → 经济性 → 交付与合规**

最终目标不是宣告“爆款”，而是选出：
- 1 个最值得进入真实测试的 `PRIORITY TEST`；
- 最多 2 个 Backup；
- 首测平台 `XIANYU_FIRST / XHS_FIRST / DUAL_TEST`；
- 最大未知项、Kill Evidence 与最低成本验证方案。

## 为什么不能直接照搬独立站选品？

独立站核心问题之一是“为什么用户不去 Amazon/Temu/Etsy 买”；而闲鱼/小红书的核心不同：

- **闲鱼**：更接近搜索型、明确需求、即时询价与平台内成交市场；低客单、价格压缩、售前沟通和争议成本更重要。
- **小红书**：更依赖内容种草、搜索发现、信任与可视化 Proof；内容兴趣与购买意图必须分开，转化路径还受平台规则与账号/类目能力约束。

因此本 Skill 保留 `independent-store-product-opportunity v2.1` 的方法骨架，但将 `DTC Wedge` 重构为 `Platform Distribution Fit + Trust/Proof Fit + Policy/Transaction Path`。

## 核心流程

```text
Current Rules Snapshot
→ Pre-Selection Intake
→ 8 Discovery Engines
→ 30–50 raw ideas
→ 15–25 normalized candidates
→ Signal Ledger / Lineage
→ Platform Eligibility Gate
→ Quick Kill
→ 5–8 shortlist
→ Critical Unknown
→ E1–E10 Decision Evidence
→ Xianyu / XHS 双平台 Opportunity Score
→ Evidence Confidence
→ Operator Fit / Objective / Horizon / Failure Cost
→ Counterevidence
→ Minimum Validation
→ PRIORITY TEST / BACKUP / HOLD / KILL / NO PICK
```

## 支持的虚拟产品形态

- 数字下载 / 模板 / 表格 / SOP；
- 个性化报告 / 审核 / 诊断；
- AI Workflow / Agent Kit / Prompt+流程产品；
- 微型 SaaS / 单功能工具；
- 服务产品化；
- 小型课程 / 训练包；
- 设计资产、定制化数字交付；
- 其他能够合法、稳定、可复现交付的数字产品。

Generic PDF、纯 Prompt Bundle、公开资料搬运默认不因“制作便宜”而加分；必须通过免费替代测试。

## 核心纪律

1. 热度不是付款；
2. 点赞收藏不是订单；
3. 卖家多不是需求强；
4. 看到别人违规卖，不代表规则允许；
5. 闲鱼证据不能直接外推小红书；
6. 平台规则、交易路径和类目资格是硬 Gate；
7. 先找最可能推翻结论的证据，再继续研究；
8. 没有候选过门槛时输出 `NO PICK`。
