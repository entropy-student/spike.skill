# Xianyu & Xiaohongshu Virtual Product Opportunity v2.0

用于反复执行的 **闲鱼 / 小红书虚拟商品选品与市场映射 Skill**。

## 默认做什么

默认不是“挑一个爆款”，而是：

> **从平台真实市场出发，整理有需求的具体商品类型 / SKU / Offer。**

核心流程：

~~~text
平台原生市场
→ 具体 SKU / Offer
→ 证据与 Signal Lineage
→ D4 / D3 / D2 / D1 / U
→ CONFIRMED / PROBABLE / WATCHLIST / MARKET_SIGNAL_ONLY
~~~

关键纪律：
- Transaction > Intent > Attention；
- 推荐页不等于搜索深度；
- 同源信号不重复计权；
- 相邻需求只生成候选；
- 货源 UNKNOWN 不否定需求；
- 不强制唯一冠军。

## 两种模式

**MARKET_MAP — 默认**  
输出商品类型 / SKU 目录；不要求货源、利润、上架、真实订单或自动化。

**TEST — 用户明确要求时**  
回答“哪个最值得卖/测试”，再增加平台规则、竞争、免费替代、经济性、交付、风险与 Minimum Validation。
