# Platform Policy Eligibility Gate

平台规则是动态硬约束。每次正式 Run 必须优先核对当期官方规则，尤其是类目、账号主体、交易能力、引流、广告 claim、知识产权和敏感行业。

## Status
- `POLICY_PASS`：当前路径明确可行；
- `POLICY_CONDITIONAL`：需要额外资质/主体/类目/交易能力；
- `POLICY_UNKNOWN`：未找到足够官方证据，默认 HOLD；
- `POLICY_FAIL`：明确禁止，KILL。

## 高风险默认 Quick Kill / 强制复核
- 盗版/破解/未经授权资料与软件；
- 账号买卖、共享凭证、代充、绕过服务限制；
- 考试作弊、代考、答案、虚假证书；
- 刷量、虚假评价、伪造数据/材料；
- 隐私数据交易、恶意爬虫、绕过安全措施；
- 赌博、违法金融/虚拟货币、非法投资咨询；
- 无资质医疗/健康效果承诺；
- 未经授权的商标、影视、人物肖像、IP素材；
- 其他当期规则禁止商品/服务。

## 路径规则
- 不得把暗语、谐音、二维码、私信绕监管等规避方式当增长策略；
- 小红书尤其必须核查当前站内交易、交易型小程序、商品或线索能力是否适用于该产品；
- 闲鱼必须核查当前商品/服务发布与卖家身份要求；
- “别人正在卖”只能是市场信号，不能作为 Policy PASS 证据。

最终报告必须写明：`rule_date / official_source / applicable_scope / status / unresolved_policy_unknown`。
