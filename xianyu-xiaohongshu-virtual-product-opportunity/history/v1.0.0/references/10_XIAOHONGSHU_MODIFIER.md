# Xiaohongshu Modifier｜小红书平台修正器

小红书核心链路更接近：**内容/搜索发现 → 问题认知 → Proof/信任 → 产品兴趣 → 合规转化**。

## H1 Search + Recommendation Dual Fit
- 用户是否会主动搜索；
- 内容是否也能被推荐场理解；
- 一个候选至少能形成多个独立问题角度，而不是只依赖单一爆帖。

## H2 Content-to-Offer Continuity
笔记解决“为什么这是问题/怎么判断”，产品解决“替我完成结果/节省时间/降低错误”。内容如果已经免费交付全部价值，产品会被掏空。

## H3 Proof Visualizability
优先：前后对比、样例页、流程演示、结果截图、交互 demo、结构化报告预览。无法视觉化 Proof 的产品通常需要更长信任教育。

## H4 Intent Ladder
`原生付款/订单 > 商品/服务明确动作 > 合格私信/咨询 > 搜索进入/主页行为 > 收藏 > 点赞/曝光`。

点赞、收藏、评论“求资料”都不能单独充当 Payment Evidence。

## H5 Content Runway
检查是否能持续拆出 20–50 个真实问题、场景、案例、误区、对比、方法或结果内容；若只能围绕一个热点反复重写，Creative Fatigue 高。

## H6 Trust / Authority
通过方法透明、样例、边界、案例、数据来源、隐私和退款规则建立信任；禁止伪造身份、资质、案例或绝对化效果承诺。

## H7 Conversion Route
每次 Run 必须确认当前账号、类目与产品可用的站内商品、店铺、交易型小程序、线索或其他官方支持路径。不得默认站外引流或规避平台监管。

## H8 Fit 判断
适合 XHS_FIRST 的典型结构：
- 问题需要教育/解释；
- 内容本身有传播与搜索空间；
- Proof 可视化；
- 信任建立后购买理由明显增强；
- 合规转化路径明确。
