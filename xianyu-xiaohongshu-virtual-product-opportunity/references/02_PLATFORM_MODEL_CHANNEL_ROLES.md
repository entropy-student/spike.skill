# Platform Model & Channel Roles

## 闲鱼
默认视为偏 **搜索驱动 + 明确需求 + 询盘议价 + 平台内交易** 的市场。

关键问题：
- 买家是否带着具体任务搜索？
- 标题/关键词能否直接表达结果？
- 同类交易是否存在，而不是只有大量挂单？
- 低价竞争是否把人工沟通成本放大到不可盈利？
- 是否能在平台允许的交易路径内完成交付与争议举证？

## 小红书
默认视为 **内容推荐 + 搜索发现 + 信任教育 + 合规转化** 的市场。

关键问题：
- 用户是否会主动搜索这个问题？
- 内容是否天然能展示问题、过程、前后对比或结果？
- 是否有持续内容空间，而不是单次热点？
- 用户是否从“觉得有用”进一步产生“需要一个产品/服务解决”的动作？
- 当前账号/类目能否使用合法的站内交易、商品、小程序或线索路径？

## 双平台纪律
- 一个产品可以在两个平台都成立，也可能只适合其中一个；
- Demand / Transaction / Competition / Policy 必须按平台分别记录；
- 不允许把一个平台的高热度当另一个平台的需求证明；
- 最终输出 `XIANYU_FIRST / XHS_FIRST / DUAL_TEST / PLATFORM_MISMATCH`。
