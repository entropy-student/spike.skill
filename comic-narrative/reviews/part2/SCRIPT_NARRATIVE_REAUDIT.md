## 1. Part 2 的任务与完成条件

Part 2 把已经通过 Part 1 的题目，变成一个机制准确、因果成立、人物具体、听起来自然、开头承诺能够兑现的漫画故事。观众应有理由继续听，也能形成准确的新理解；不是把定义套上人物，也不是用一个故事替未经核实的结论作证。

负责三件事：

1. 确认这一期究竟能讲懂什么，依据是什么，什么还不知道；
2. 让人物欲望、行动、发现、后果和选择构成独立有价值的故事；
3. 写成最终口播，并把必要事实、非口播事件、对白与语义节奏完整交给下游。

Part 2 通过意味着机制 / 故事 / 文本已达到可锁稿质量，接口充分。它不意味着配音时长已满足目标、分镜能直接生图、最终成片好看或观众留存已经验证。

保留当前频道配置：Bilibili 为主要平台；标准目标 3–5 分钟，故事自然讲完优先；固定第一人称频道角色为默认入口；故事理解型 / 故事行动型为两种编辑模式。较短内容沿用准确性、因果和兑现要求，减少承诺和展开范围，不恢复70–85秒统一标准，不靠讲课填满时长。

## 2. 输入与模块边界

### 2.1 从 Part 1 接收什么

至少能识别：题目与通过状态（PASS / REVISIT）、目标受众和人的问题、WHY / 预期落差、主机制候选及已有来源、不确定性、观众预期收获、内容任务，以及重复 / 重讲边界。

已有材料可以引用，不要求把 Part 1 全部字段重填一遍。若 Part 1 提醒故事母题重复，Part 2 在故事层处理；纯视觉构图 / 站位提醒转交 Part 3。不能只换领域、人物名字或道具，仍写同一个“犯错 → 灾难 → 折中”故事。

Part 1 的意义种子不是必须证明的观点。Part 2 可在题目范围内具体化故事和表达；若研究发现主机制、核心 WHY 或受众收获需要实质改变，返回 Part 1 / 原选题决定，不能偷偷换题。

### 2.2 谁决定什么

| 决定 | 所属职责 |
|---|---|
| 选题是否值得做、历史重复、重讲条件、主要受众与题目承诺 | Part 1；Part 2承接并提出冲突 |
| 机制核心、证据范围、人物欲望、事件因果、重要事实身份、发现 / 转折 / 最终选择与文本 | Part 2 |
| 对白说话者、口播轮次、语义停顿和句尾落点的意图 | Part 2 |
| 按已确认声音 / 配音方案实现实际语速 / 停顿、最终音频、真实对齐SRT | Part 2.5；声音选型与确认沿用生产配置，未明确时列为待决定项 |
| 整集视觉载体、Scene System / Scene Anchor、镜头 / 摄影POV、单帧状态、视觉reveal与画面切换 | Part 3，受已锁故事约束 |
| 参考绑定、图片source、prompt、执行 / 素材技术决定 | Part 4 / 4.5及执行模块 |

Part 2 决定“发生什么、为何发生、谁知道什么、何时知道”，不决定每个事实必须拍几张图、使用哪种景别或几秒后切。Part 3 可以落实站位、表情、道具呈现等视觉细节，不能为画面丰富发明关键行动、结果或证据。

## 3. 工作顺序与锁定权限

```text
承接已通过题目与已有依据
→ 确认机制与证据边界
→ 设计 / 检查故事前提与信息释放
→ 写口播与必要非口播说明
→ 事实、故事、口语和交接QA
→ 锁定同一版本
→ Part 2.5 最终音频 / 正式SRT
→ Part 3
```

机制、故事、Writer 是三类判断，不要求三个Agent、三轮Owner审批或三个额外流程。一个Part 2 Agent也可以完成，但必须知道哪些已经锁定，哪些仍是自己的草案。

机制先锁定，再允许故事探索；前提确认后，Writer优化表达，不静默改变欲望、核心事件因果、转折意义和题目任务。发现更好的因果结构时，可以明确重开本模块前提、说明变化依据并重新检查；不是“因为顺口就把已经停下的退款改成已经退完”。已有Owner确认的内容仍受原确认范围约束。

最终锁稿包括同一版本的机制核心、故事前提、口播及必要语义说明。需要改关键事实，先回机制 / 研究；需要改事件因果，先回故事；只改句法 / 口语则修文本。修改后统一重锁，不能人读稿已经改了而下游仍用旧机器文本。

这是现有锁定 / RETURN 思想的轻量落实，不新增普遍强制审批门。现行旁观 / 听说叙事入口的Owner确认门继续保留，见§7。

## 4. 机制核心：研究结论与故事演示分开

### 4.1 锁定最小知识范围

明确核心概念与一个主要机制、关键主张、常见误解、适用条件、不能推出的结论、不确定性、普通人的实际意义及来源。

需要时带上产品 / 版本 / 时间 / 情境范围。新闻 / 产品能力等易变化的关键依据，在锁稿前核对相关范围；旧材料存在或曾PASS，不保证现在仍适用。无需为普通修辞句建大型证据账本。

对核心因果、数字、具体产品能力和强结论，能指出来源支持哪一部分，不能只有一串相关链接。找不到关键原件时标 `NOT VERIFIED`；它不是发布通行证。若不能补证、缩小命题或明确表达未知，返回研究 / 选题。

### 4.2 一个主机制不等于一个事实

一条内容默认只有一个主机制与主要收获。必要条件、辅助事实、例外、实现范围可以服务同一个问题；不能因为还有一条辅助知识就删去准确性依据。若核心解释必须依赖两个机制共同成立，不能仅把第二机制称为“辅助事实”；按现行Part 1缩窄题目、拆题 / 返回。需要独立展开与回报、改变主问题的第二机制同样返回。

例如推荐选择与新偏好形成的故事，同时引用推荐排序和重复接触研究，不因它们服务同一问题就自动通过一个机制检查。应判断后者是必要条件 / 有限支持事实，还是构成不可缺的第二因果机制；不能简单删掉它的依据，再用虚构吃面经历证明人的偏好规律。需要放宽Part 1硬门时应明确提案，由Owner决定，本候选没有默许放宽。

### 4.3 四种说法不能互相升级

| 内容 | 合法表达与限制 |
|---|---|
| 有证据的一般机制 / 事实 | 保留适用范围；一般规律不自动证明本次个案原因 |
| 具体个案事实 | 需要个案依据；没有依据不能画 / 写成已调查证明 |
| 人物怀疑、解释假设、主观脑补 | 保持人物立场 / 未证实属性；不因戏剧需要升级为客观后台事实 |
| 有边界的观点或判断 | 来源于机制及故事选择，但不是经验统计结论或普遍处方 |

不知道具体原因本身可以进入故事：调查排除误读、识别条件、承认无法证明、改变判断。前提是题目和Hook诚实承诺这种收获，不能标题承诺破案，正文只给几个可能原因。

“故事先证明”在叙事层指让人物选择及后果体现意义；研究事实依然由证据支持。虚构模拟和比喻只能演示已支持的关系，不能验证产品确实这样运行或某平台针对个人。

## 5. 题目如何变成故事，而不是案例讲义

先找到具体的人想得到什么、为什么这件事值得他行动、世界怎样回应，以及观众为何关心。代价可以小而具体，不必制造灾难。

保留核心因果：

```text
欲望 / 触发
→ 人物行动
→ 预期与结果落差
→ 后果、知识、策略、关系或选项改变
→ 新行动 / 发现
→ 转折
→ 理解 / 选择 / 结果
```

机制成为故事规则：行动在明确条件下产生结果，发现改变下一步。它也可以是信息使用失败、一般规律与个案无法等同，而非每次都制造一个外部灾难。

去掉术语后仍有值得跟随的因果故事；但不能为No-name Test删掉重要限定，让故事变准确性不足的寓言。人物不能只是听老师解释，也不能所有行动都来自“主题需要这一步”。

检查转折：人物凭什么知道？谁告诉他、他看见什么、发生什么、前面的伏笔怎样兑现？关键理解不能只是“后来我突然想通了”。Part 2 锁定发现的根据和故事事件，Part 3 决定怎样让观众看见。

## 6. 故事发动方式、渐进与呼吸

事件驱动适合行动 / 委托 / 钱 / 工作 / 关系后果；比喻驱动适合难直接看见的认知与系统边界。保留两种已验证入口，不把它们视为所有题材的穷尽清单。调查、重复摩擦、对比等可以在同一因果原则下工作，不另建大量模式。

比喻必须能持续发生事情：状态变化 → 行动 → 后果 → 再变化 → 理解。仅说“像一张桌子”然后讲定义不够。记录它对应真实机制的关系和不对应的性质，避免桌面可见暗示完美记住、笔记存在暗示所有产品必然成功检索，或拟人行为被当成技术机制。

主要叙事单元应推进人物 / 观众状态。不是每句、每个换行、每个对白轮次都要包含完整“欲望→行动→后果”。必要背景、证据阅读、反应、伏笔、setup、停顿、回扣与准确性说明可以服务同一变化。

删除测试看因果、理解、张力、节奏和后续兑现是否受损，不只看下一句是否还能语法接上。反复相同麻烦若仅换名字，合并 / 改写；有意重复摩擦可以累积成本、暴露错误策略或强化落点。

重要变化与小段呼吸交替。允许人物暂时得意、犹豫、沉默或开玩笑，不让每段都像案例培训中的“问题→教训”。保留因果，不保留固定三幕比例、分钟转折或“犯错→灾难→矫枉过正→折中”模板。

## 7. 叙事入口、角色与真实性

沿用第一人称频道角色默认入口。角色是当事人，有欲望、习惯与错误判断，愿意修正；不是知道答案的知识主持人。固定的是人格 / 关系和语言来源，不是每期都偷懒翻车、相同口头禅或同一地点。半固定世界、常驻地点与关系可以按故事需要复用，不设场景数量或强制资产库。

旁观 / 听说只在更自然、更有戏或更符合真实性时建议；按照现行Owner决定，先确认再锁StoryPremise。这个门针对整集叙事入口，不针对配角对白中的“他”、第三人称描述、摄影POV或每个主观段落。

没有确认，不自动切换入口；同时不得编造现实个人亲历。可先做不依赖入口的机制工作 / 草案，默认亲历只有在真实依据充分或清楚的虚构频道故事可成立时才使用；两者都不成立就不锁前提，返回说明选择冲突。

在交付中明确实际真人经历、真实外部个案、虚构频道故事 / 模拟，及需要特别识别的回忆、主观想象、假设、计划、一般示范。正文 / 制作方式也须让观众能辨认虚构身份，不能只在内部备注“虚构”，播出却假装亲自测了某真实平台。

Part 2 决定事实身份与故事授权；Part 3 决定可执行的主观视觉语法和Scene Anchor。已有机制支持、不会冒充个案证据的一般示范可由Part 3视觉落实；新增本集客观事件 / 个案证据、超出机制支持范围或改变因果意义的示范须回Part 2，不由执行器为解释方便补写。

## 8. 故事结构与信息结构一起设计

故事顺序解决事件因果，信息顺序解决观众何时知道足够多、期待什么、哪次发现改变理解。两者相关但不等同。

内部用一句话保留观众主要问题与最终收获；承接Part 1的WHY，不强制新增独立表单。逐个主要段落核对：现在的人物状态、观众已知、仍未知、下一步为什么值得看。不要隐瞒理解前提制造假悬念，也不要一开始解释完核心误读再演半集已经知道的结论。

关键reveal有来源和语义落点；哪些是人物早就知道但观众未看到，哪些是人物刚发现，要分清。标题、开头与收束承诺一致；可以回扣开头，但回扣一句话不等于已经回答机制问题。

## 9. Hook、发现、转折与回报

不强制自我介绍、百科背景或夸张坏结果。优先事件 / 反常入口，或欲望立即触及冲突。具体处境、矛盾 / 未知、不懂术语也想继续听，是实用自检，不是“2/3打勾就自动PASS”。

Hook强度不能超出锁定机制和正文兑现。人物夸张 / 玩笑需要可辨并有后续真实承接；“新偏好较少形成”不能无条件包装成“算法消灭口味”。先检查观众会怎样理解，再决定是否保留夸张。

转折来自新证据、行为结果、矛盾暴露或选择，而非插入正确答案。收束至少兑现：开头的问题、人物经历的主要困难、机制理解 / 最终选择之间的关系。

若给判断规则 / 新策略，检查前面关键失败是否被它解释或保护。规则之外的个人价值 / 优先级不能在结尾悄悄丢失。按故事需要，用一个结果、新选择或新情境检验让回报可见；不强制每篇再加一轮测试。发现规则仍未完整覆盖，可以明确局限，而非补一句“后来顺了”就结束。

## 10. 解释、术语与观点

解释服务故事与准确性。通常具体事件 → 预期落差 → 形成直觉 → 命名 / 最少解释 → 回到结果。不按百分比限定；桥、关键区别、例外、不确定性可以改变理解，本身有价值。

术语默认在命名能帮助理解时出现；热点 / 搜索对象或理解前提必须早提时可早提名字，仍不以定义代替故事。首个专名顺手说明不等于提前讲架构课，也不能为悬念拖到观众一直不知“它”是谁。

准确允许时用两句对比、已出现的事件 / 物件 / 状态或已建立比喻；不能为了“两句”删除条件与例外。连续解释段检查它增加哪个区别、为何此刻需要、怎样影响判断 / 下一事件；不是见第三句就自动RETURN，也不靠人物拿手机掩饰说明文。

观点可成为中心意义，但不必须有。开放问题先于规范性结论，事实问题已有证据答案不必装作作者未知。真正的取舍有吸引力的反方向，不能制造稻草人；已被证据否定的说法不因此获得同等地位。

观点来自事实 / 机制及人物后果，默认0或1个主要判断，边界明确。允许简短点明必要意义，不要求“观点只能是余味”；也不把一例推成所有人 / 整个行业 / 必然未来。不做鸡汤升华，不反复宣讲主题。

## 11. 口语、对白、潜台词与幽默

表面是聪明但不端着的人讲自己卷入的事：具体、长短句自然混合，有真实反应，技术从事件中长出来。风格借鉴不复制原句、角色、笑点或镜头。

一个句子一个主意思，代词有对象，专名 / 数字串 / 缩写能说清。重要对白是在试探、争取、回避、解释自己、决定、揭示或反转；不是每句都要机智、潜台词或藏答案。旁白与每个角色轮次要能辨认说话者。

能由动作、反应或后文选择表达的感受，不再重复贴标签；若没有已定义行为或声音无法辨认，则不能仅为了“潜台词”删掉必要信息。非口播动作要写入前提 / 简短制作说明，不能寄望Part 3自行补事件。

删掉同义复述、无功能提纲标记、重复总结和演讲腔，保留理解需要的自然衔接。自动化、外包、bug、退货、审批、成本等是可选语言来源，不强制每期使用。

幽默来自反应、荒诞后果、习惯或连续比喻。没有笑点配额；主梗集中是倾向，不强加1–2个。不能新增假事实、打断因果或把角色变成纯吐槽主持人。“轻盈”也可以没有笑话。

## 12. 语义节奏与 Part 2.5 交接

Part 2 可提示积累、包袱setup、落点、反转、反应、收尾与有意义停顿。只在关键位置说明作用，绑定到明确文本片段 / 前后词句，不要求逐句标签、强制Speech Unit或猜毫秒。

将真正朗读的文本与角色名、动作说明、节奏标签、标题、来源及QA备注分开；用同一锁稿版本供配音，不能让“停顿 / 主角皱眉”被TTS读出来。旁白 / 对白说话者和轮次清楚，关键数字、名称与易误读词提供必要读法意图。Part 2.5依据已确认声音 / 配音方案实现读法与真实时长；声音选型 / 确认责任沿用生产配置，未明确时列为待决定项，不授予Writer或Part 2.5自行换声的权限。

关键末词延迟、reveal前先建立预期等语义意图需传递，不能只靠Markdown换行代表必须暂停。画面切点与视觉reveal由Part 3在真实音频范围内决定，受同一信息边界约束。

配音方案未确定或音频是DRAFT，不作为正式时间。Part 2.5发现漏 / 多词、语义错误、节奏落点被破坏，修语音或回Part 2；不静默改稿。锁定口播 / 配音意图实质改动后重做受影响音频 / 对齐，并重审相关下游；不能把不同口播的SRT沿用。仅非口播说明变化按§17核验实际影响。

## 13. 时长与较短版本

3–5分钟是编辑目标，不是字数配额。写长靠行动 / 后果 / 发现 / 选择变多，不靠同义解释变长；写短减少展开与次要困难，保留主因果、关键证据 / 限定和回报，不把结尾变成定义速记。

锁稿前做一次连贯出声试读 / 等效口语预读，检查绊嘴、指代、长定语、重复、信息负担和节奏。实际未试读就不声称听觉已验证。可作DRAFT范围判断，不能用固定字速或读稿估时生成正式SRT，不新增必须付费的试听阶段。

正式采用音频的时长由Part 2.5给出。若实际时长与目标有明显冲突，先判断目标是否确实必要和故事是否自然完整；必要时回Part 2删背景 / 重复 / 弱例子，或调整内容范围后重新锁稿。不得靠临时加速、Part 3快切或拉长hold伪造适配；合理短于目标时可提出保留理由，不凑分钟。

较短能力有历史文本验证，3–5分钟稿也有历史候选 / 生产稿；当前新时间链下的稳定成功率和真实受众效果仍需生产证据，不因这些材料存在就声称已稳定量产。

## 14. 两种编辑模式与业务任务

保留故事理解型：故事 → 机制 / 心智模型 → 新理解 / 判断 → 可选观点。

保留故事行动型：故事 → 理解 → 一个稳定可迁移的判断 / 行动。方法必须直接来自本期机制、有依据且相对稳定、无需第二个独立机制、自然解决 / 延伸本期问题、足够小且改变行为；否则理解收束已足够。

方法优先判断规则、分类、诊断问题、边界 / 风险规则，不在结尾附编号教程。发现 / 信任 / 解决是主要业务任务，和编辑模式分开；承接已有任务，缺失时在本集编辑范围内说明选择，不强加销售、CTA或产品。

不恢复教程第三模式、每条必有观点 / 方法 / CTA、固定发布组合或70/30配额。发布分析、转化与长期反馈不由Writer新增常设系统。

## 16. QA：不只问“有没有故事字段”

### 16.1 事实与前提

- 关键主张有依据和适用范围，核心 / 个案 / 假设 / 观点没有互相升级；
- 虚构故事、比喻不被当作机制实证，角色认知不等于客观事实；
- 主机制确实关联事件和理解；欲望 / 第一次行动不是为主题机械设计；
- 发现有根据，困难改变局面，重要事件已写明，下游无需造因果。

### 16.2 整稿故事质量

连续读全稿，再用不懂术语的观众立场复述：谁要什么、哪里出了问题、为什么下一段值得听、什么证据改变判断、最后得到什么。不能复述时定位具体文本，不用总分代替判断，也不冒充真实观众测试。

核对开头承诺和结尾兑现点、主要疑问如何逐步回答、最有吸引力的处境是否被背景埋住、关键前提是否过晚、张力和释放、重复段的新增价值、结尾选择是否覆盖前面的主要失败。

必要解释不能只因句数被删；故事结束后突然开始百科仍应返回。没有人物行动的新后果，不自动判失败：证据阅读 / 不确定性被识别也可推进；只有相近概念被重述则不能靠下游多换机位挽救。

### 16.3 口语与交接

检查指代 / 呼吸 / 专名 / 数字 / 抽象词负担、角色语言、对白轮次、潜台词是否真的有可依托事件、包袱是否被解释提前说完。只检查黑名单0命中不证明口语好。

核对纯口播与说明分开、事实 / 术语对应、停顿与reveal语义锚点、版本及锁定状态齐全。未试听、未做真实音频或成片的项目，标明尚未验证，不能按文档PASS推广为生产PASS。
