# AI Domain Adapter — Topic & Knowledge v0.2

Status:
`CANDIDATE / extracted from validated AI workspace`

## Role

Specialize generic Story Showrunner for AI/technology topics.

The core remains domain-neutral.

## AI signal sources

Prefer factual authority:
1. first-party product/research/docs/changelogs
2. primary open-source release/project sources
3. reputable reporting for context
4. trend/platform signals for demand discovery
5. owned audience questions/comments for problem discovery

Trend aggregators discover signals; they do not become technical truth.

## AI TopicOpportunity

Default translation is human-world-first:

```text
human-interest X / observable situation
→ Human Process Family
→ observed paradox
→ WHY
→ Human Tension
→ Meaning Fingerprint
→ AI Changed Process
→ causal AI mechanism
→ storyable human stakes
```

Strong AI-first signals may use the compatibility path:

```text
model/product/protocol/feature/event
→ capability or system change
→ audience translation
→ Human Process / human consequence
→ WHY / Human Tension
→ Meaning Fingerprint
→ causal AI mechanism
→ storyable situation
```

Do not stop at “What is MCP/Agent/RAG?”

## AI hard gates

Pre-gates:
- X remains interesting without AI jargon when using Human-world-first entry;
- Human Process Family is explicit;
- there is a real paradox / WHY gap;
- Human Tension is open enough to test rather than a disguised answer;
- AI Changed Process identifies what AI changes/ compresses/ replaces/ amplifies.

Hard gates:
- source/evidence is traceable
- ordinary person can care without knowing the acronym
- exactly one main mechanism by default
- causal mechanism is technically accurate
- story can show actions/consequences
- payoff is more than “AI can do X”
- recent content is not the same mechanism + human process + human problem + payoff in disguise;
- D5 Meaning Duplicate passes across X domains

## No-name test

Remove names such as:
- OpenAI
- Anthropic
- Google
- MCP
- Agent
- RAG

If the human problem/story no longer matters, the topic is too dependent on jargon/brand.

## Duplicate fingerprint

Topic:
`mechanism + human_process_family + human_problem + audience_payoff`

Meaning:
`meaning_fingerprint ≈ human_tension + controlling_question_seed`

Surface:
`story_motif + hook_pattern + visual_motif`

## HOT / EVERGREEN

HOT:
recent AI change/event that survives all hard gates and can be produced before its useful half-life expires.

EVERGREEN:
prefer Human-world domains/processes that remain useful without a current event; the legacy AI behavior/problem/mechanism bank remains valid as a fallback and mechanism reserve.

Qualified HOT may override a planned Evergreen runtime slot.

## KnowledgeCore

For AI, explicitly lock:
- what changed
- actual mechanism
- what the mechanism does NOT imply
- product/version/time scope
- uncertainty
- misconception
- ordinary-user consequence

Avoid:
- benchmark-number trivia without consequence
- company news without human stakes
- broad “AI will definitely...” predictions
- anthropomorphism presented as mechanism

## Good mechanism families

Examples:
- context / memory / retrieval
- hallucination / uncertainty
- tools / API / MCP / interoperability
- agents / delegation / approval
- search / RAG / evidence
- multimodal
- training / fine-tuning / distillation
- evaluation / safety / privacy
- coding / computer use / workflows

These are supply families, not ready-made titles.
