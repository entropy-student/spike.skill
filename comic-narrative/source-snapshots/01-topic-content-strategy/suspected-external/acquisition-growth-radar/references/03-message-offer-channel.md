# Growth Levers｜增长变量

## 核心原则

证据回答：

> **实际发生了什么？**

Growth Lever 回答：

> **我们可以改什么？**

不要把 Message、Offer、Channel、Trust 等变量当成 Evidence 阶段。

v0.2 的核心 Levers：

1. Audience / Situation
2. Message / Creative
3. Proof / Trust
4. Value Experience / Activation
5. Offer / Price
6. Conversion Path / Friction
7. Channel / Distribution

---

## Message / Creative

任务不是“做漂亮内容”，而是验证：

**哪个 Problem × Situation × Hook × Proof Format × CTA 能推动下一步行为。**

常见母题：

- Problem
- Before / After
- Demo
- Comparison
- Challenge
- Education
- Routine
- Testimonial / Reaction
- Objection Handling

Winner 不是播放量最高，而是对后续商业行为贡献最大的表达。

---

## Proof / Trust

Trust 是横向变量，而不是固定阶段。

```text
               TRUST
────────────────────────────────→
Attention → Interest → Activation → Intent → Transaction → Retention
```

诊断时始终区分：

> **用户是不想要，还是不相信？**

常见 Trust Levers：

- Proof / Demo
- Reviews / Social Proof
- Authority / Credentials
- Transparency
- Guarantee / Risk Reversal
- Refund policy
- Privacy / Security
- 清晰身份与品牌信息
- 真实适用边界和限制

---

## Value Experience / Activation

Activation = 用户第一次亲自体验到核心价值。

如果 Interest PASS 但 Activation FAIL，优先检查：

- Onboarding
- Demo / 试用设计
- Time-to-Value
- Promise 与实际体验是否匹配
- 核心产品/服务本身
- 价值呈现
- Trust

不要把“完成注册”自动视为 Activation。

---

## Offer / Price

Offer 不等于价格。

Offer 至少包含：

**Value Outcome + Delivery + Price/Exchange + Risk Reversal + Reason to Act + CTA**

需要回答：

- 用户具体得到什么结果？
- 交付什么？
- 为什么值得这个交换条件？
- 用户承担什么风险？
- 如何降低风险？
- 为什么现在行动？
- 下一步是什么？

### Free Value → Paid Expansion

```text
Free Value
= Complete but bounded win

Paid Value
= More Depth
+ More Scope
+ More Speed
+ More Personalization
+ More Continuity
+ More Certainty
```

> **免费证明价值，付费扩大价值。**

不要故意把免费体验做残。

---

## Conversion Path / Friction

转化路径不限于网站，可以是：

- 商品页
- 私信
- 表单
- 电话
- Demo
- 免费试用
- App onboarding
- 预约
- 门店
- 平台页
- 合同

常见摩擦：

- 不理解价值
- 不相信
- 不知道是否适合自己
- 风险太高
- 价格缺参照
- 下一步复杂
- 支付/表单/预约摩擦
- 社会证明不足
- 时机不对

---

## Channel / Distribution

渠道是放大和获取样本的工具，不是天然的第一步。

评估五项：

1. Audience Fit
2. Message / Medium Fit
3. Tracking Quality
4. Test Cost
5. Scale Potential

常见渠道：

- Organic Content
- Search / SEO
- Community
- Creator / Influencer
- Partnership
- Affiliate
- Referral
- Email / Lifecycle
- Direct Outreach
- Marketplace / Platform
- Paid Media
- Offline / Event / Retail

### 关于 Paid

不要把“必须先 Organic 再 Paid”当绝对规则。

如果小预算 Paid 是获得高质量验证数据的最低成本方式，可以使用，但必须：

- 明确实验目标
- 有预算上限
- 有 Kill 条件
- 有可读的行为指标
- 不用付费流量掩盖产品/Offer 问题

---

## 单变量纪律

一轮实验优先只改一个核心 Lever。

如果必须同时改变多个核心变量：

- 明确承认归因会变弱；
- 不要把结果归功于其中某一个变量；
- 需要严格判断时，拆成 Full Acquisition Cell。
