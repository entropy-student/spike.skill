# Visual Profile — Simplified Flat Narrative Comic v0.1

Status:
`VALIDATED_CONTROL_PROFILE / Skill Candidate`

## Purpose

Current production visual baseline.

This is a profile, not universal Frame Blueprint logic.

## Style direction

`SIMPLIFIED_FLAT_NARRATIVE_COMIC`

Goals:
- recognizable recurring IP
- low drift across many stills
- expressive enough for reaction/action
- efficient image generation/edit
- strong story readability over decorative polish

## Rendering tendencies

Prefer:
- simplified shapes
- readable silhouettes
- restrained texture
- limited micro-detail
- clean background hierarchy
- clear focal object/action
- comic/narrative staging

Avoid:
- polished anime glamour as default
- hyper-detailed environment rendering
- neon cyber-AI aesthetic
- infographic/PPT aesthetic
- decorative clutter
- cute/chibi reinterpretation of adult characters

## Simplification guard

> Simplified rendering != simplified anatomy.

Visual simplification may reduce rendering detail.
It must not change identity maturity, face/body proportions or canonical costume.

## Composition

Frame architecture outranks decorative complexity.

Default:
- one obvious primary focus
- secondary focus only if causally useful
- suppress irrelevant props/text
- reserve subtitle-safe area without turning frame into a slide

## UI / evidence

UI/document visual assets may be generated/edited as images.

Exact critical text should usually be POST_OVERLAY.

Do not invent brand names/logos to make UI feel real.

## Continuity

Prefer DERIVE_EDIT when one state delta can be preserved safely.

Generate fresh when target POV/composition/subject set is materially different.

## Calibration

Manual key-frame sampling is triggered only by:
- new style
- provider/model change
- new recurring character
- repeated new failure class

It is not a per-episode approval gate.
