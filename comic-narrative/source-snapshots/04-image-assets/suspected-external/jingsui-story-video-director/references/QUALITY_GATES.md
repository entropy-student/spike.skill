# QUALITY GATES V3.4

## Script Gate
- [ ] 第一行是 `大家好，我是{{IP_NAME}}。`
- [ ] 签名后 1–2 句内进入具体人物、事件或处境
- [ ] narrator 是当事人，不是导师
- [ ] 抽象主题若适合，至少有一个具体人物/事件承载
- [ ] 前 50–60% 以事件、观察、反应、梗链和证据为主
- [ ] 核心观点没有在前 1/3 提前完整说完
- [ ] 主梗母题不超过 2 个，至少一个形成连续 2–5 句的 riff
- [ ] 笑点来自当前事实，不是平均撒独立段子
- [ ] 至少 1 个具体现实摩擦点
- [ ] “边说边修正”默认 0–1 次，且必须语义自然
- [ ] 未出现“很多普通人的问题是 / 现代人的通病是”等概念化演讲腔
- [ ] 结尾回到 narrator 本人，而不是建议清单
- [ ] 没有复制参考样本原句、角色、现成段子或既有镜头
- [ ] 预计整体 5.7–6.2 字/s
- [ ] 中文结尾完成闭环
- [ ] 默认有一句简短、略带直译感的英文尾签

## SRT Gate
- [ ] 9–18 字为主
- [ ] 按意群拆
- [ ] punchline 有足够阅读时间
- [ ] 英文尾签独立 cue
- [ ] 有最终配音时重新按真实音频对齐

## Shot Gate
- [ ] 每次换镜有语义理由
- [ ] 中位节奏目标约 2.7s，而非机械 3s
- [ ] 50% 以上为人物 / 动作 / 关系 / 荒诞联想
- [ ] 不连续 3 镜信息卡
- [ ] 脑内联想后能回现实主线
- [ ] 有少量标点型镜头但不滥用
- [ ] 最后 10–18s 降低视觉密度
- [ ] visual beat 数量不等于完全新生图数量

## Visual Gate
- [ ] 原创男主稳定
- [ ] 服装 / 发型 / 比例稳定
- [ ] 白 / 浅底为主
- [ ] 小场景只保留叙事所需物件
- [ ] 复用已有资产优先于重新生成
- [ ] 不把极简漫画误做成精致插画或 PPT
