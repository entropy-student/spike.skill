# IMAGE GENERATION PROTOCOL V3

## 顺序

Character Anchor → Action/Expression Pack → Scene Masters → Story Shots → Metaphor Shots

## 不要逐镜随机生

同一场事件放同一批生成。

例如：
饭桌 Master → 父亲说话 → 母亲反应 → 男主反应 → 荒诞脑补 → 回到饭桌。

## Prompt 必填

CHARACTER_ANCHOR
SCENE_ANCHOR
SHOT_SIZE
ACTION
EXPRESSION
PROP
RELATIONSHIP
CONTINUITY
NEGATIVE

## 荒诞联想镜

允许脱离现实，但必须保留一个与现实场景相连的锚点（人物、物件或动作），让观众知道联想从哪里来的。

## 中文文字

尽量后期叠加，不让生图模型负责长中文。
