## Rules

1. The index records only packages that have a durable package archive and an explicit status.
2. Supported package formats are `ZIP` and `EDITABLE_DIRECTORY`.
3. A ZIP uses its repo-native/package SHA-256; an editable directory uses the aggregate SHA-256 recorded in `PACKAGE_DIGEST.txt`.
4. Canonical recurring references remain under `part3/assets`; package manifests record the exact identity/hash used and Part X may deduplicate those binaries.
5. A newer package revision must be added explicitly and may mark an older revision superseded; never silently repoint an existing record.
