# Part X — Material Package Library

## Purpose

`partX` is the canonical GitHub registry for completed / retained material packages produced by `comic-narrative`.

It is an archive/index layer, not an additional production stage. Part 0–4.5 continue to own topic, script, timing, visual direction, image planning, and reuse rules.

## Storage policy

- GitHub stores package registry records, status, hashes, source lineage, and canonical reference pointers.
- Full ZIP packages are stored in the persistent ChatGPT Library under `/X部分_OWNER认定执行包/`.
- Do not duplicate recurring Character Master / Style Plate binaries inside Git history when the same canonical assets already exist under `part3/assets`.
- A package record is valid only when its Library path, package filename, SHA-256, revision, and project status are explicit.
- Invalid / superseded packages remain traceable but must not be silently presented as current.
