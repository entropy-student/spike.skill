# 漫画叙事

## 当前目标

把现有分散的 AI Story Showrunner 规则逐步收敛成更简单、可执行、可验证的漫画叙事 Skill，同时不丢失已经验证过的重要能力。

## 六个模块

1. 选题与内容策略
2. 剧本与叙事
3. 分镜与视觉导演
4. 角色 / 图片 / 资产体系
5. 配音 / 时间轴 / 成片
6. 执行与项目管理

## 当前阶段

仅进行 **Part 1：选题与内容策略** 的源材料收集。

当前没有：
- 删除旧规则；
- 合并规则；
- 改写原项目；
- 改写 `story-showrunner`；
- 宣布新的 Canonical；
- 用本 Draft 替代任何现有运行流程。

## 整理原则

- 先复制，再简化；
- 原始材料永久保留在 `source-snapshots/`；
- 简化版本与源快照分离；
- 每次只整理一个模块；
- 每个模块整理后先跑多个 Case；
- Case 通过且 Owner 确认后，再进入下一模块；
- 发现信息损失时，以源快照回补，而不是凭记忆补写。

## 使用限制

当前状态为 `DRAFT_SOURCE_COLLECTION`。

在 Part 1 尚未完成“简化 → Case 验证 → Owner 确认”之前，本 Skill 只能用于整理与对照，不应被当作正式生产 Skill 执行。
