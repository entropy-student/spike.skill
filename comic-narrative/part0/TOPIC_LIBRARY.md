# Part 0 — 历史选题库

本文件是漫画叙事的历史选题库。  
当前包含 **20 个按 Part 1 选题策略跑出的 Case**。

规则：
- 只记录已经通过选题策略检查、可作为历史参照的题；
- 新候选在最终 PASS 前必须与本库做 D1–D5 复查；
- 正式进入制作的选题应继续追加到本文件；
- HOT 题未来应在 Source / Signal 中保存真实来源或事件标识，便于 D1 复查；
- 题面优先使用普通人自然会说的话；
- “科技”包含人工智能，但不强行把推荐算法、平台设计、自动化、设备等都写成人工智能；
- 选题不默认走“反思科技代价”，允许惊奇、机制、实用、判断、趋势、探索、体验等方向。

## H001 — 美食推荐

- 最终选题：**一年只吃评分最高的餐厅，为什么后来什么都不好吃？**
- 选题类型：惊奇 / 反思
- Entry：HUMAN_WORLD_FIRST
- X：美食
- Human Process：餐厅发现 / 口味形成
- Human Problem：推荐越来越准，但自己的探索与口味形成越来越窄
- 反常：推荐越来越“最优”，主观体验却越来越没惊喜
- Human Tension：最优化 vs 探索
- Controlling Question：当系统越来越会替你选“最可能喜欢的”，你还会不会形成新的喜欢？
- 科技改变的过程：推荐系统的排序压缩主动探索和随机发现
- 主机制：推荐系统持续优先高概率匹配，会降低探索暴露
- Audience Payoff：理解“更准的推荐”不等于“更丰富的体验”
- Meaning Fingerprint：`OPTIMIZATION_VS_EXPLORATION`
- Motif：连续去高分餐厅 → 越来越相似 → 主动走进无人推荐的小店
- Content Job：DISCOVERY
- Source / Signal：EVERGREEN_CASE
- Status：PASS

## H002 — MBTI / 性格画像

- 最终选题：**人工智能测出来的性格越来越准，这个标签到底该信到什么程度？**
- 选题类型：判断
- Entry：HUMAN_WORLD_FIRST
- X：MBTI / 身份
- Human Process：自我理解 / 身份判断
- Human Problem：越来越准确的历史画像被误当成未来边界
- 反常：描述越准确，本应更了解自己，却可能越来越按标签限制未来选择
- Human Tension：被理解 vs 被定义
- Controlling Question：一个对过去很准确的画像，有没有资格决定你以后会成为什么人？
- 科技改变的过程：把零散历史行为持续归纳为稳定画像
- 主机制：模式归纳能描述已有证据，但不能把概率描述变成人的固定边界
- Audience Payoff：区分“理解过去”与“定义未来”
- Meaning Fingerprint：`UNDERSTANDING_VS_DEFINITION`
- Motif：AI画像越来越准 → 主角开始按画像选工作/关系 → 做出画像之外的选择
