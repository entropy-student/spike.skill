# Independent Store Product Opportunity（独立站选品决策系统） v2.1

一套面向独立站 / DTC 的通用“产品机会发现 + 决策验证” Skill，支持实物、数字产品、个性化报告、AI Skill / Workflow、微型 SaaS 等。

## 核心原则

**Discovery 不等于 Decision。**

- Discovery：趋势、社交、评论、榜单、交易结构、人工服务，只负责广泛发现候选；
- Decision：真实问题、真钱、市场深度、时机、竞争、获客、DTC 购买理由、经济性、交付风险；
- Test Priority：再结合本次用户临时输入的资源、商业目标、时间周期、验证成本和失败成本，决定先测什么。

## v2.1 新增：正式筛选前先问用户

Skill 本体**不包含任何用户个人画像或历史项目偏好**。

正式选品前，只询问当前对话中未知且会显著改变结果的条件，默认最多 6 个：

1. 目标市场 / 语言；
2. 允许的产品形态；
3. 商业目标；
4. 测试预算 / 最大损失 / 希望多久拿到证据；
5. 硬约束与风险容忍；
6. 可利用的能力、受众、供应链或获客资产。

用户回答只用于**本次运行**，不写回 Skill。

## 最终输出

不是“爆款榜”，而是：

- 1 个 `PRIORITY TEST`；
- 最多 2 个备选；
- Market Opportunity；
- Evidence Confidence；
- Operator Fit；
- Cost-to-Learn / Cost-of-Being-Wrong；
- 最大未知项；
- 最小真实验证方案。

如果没有任何候选达到标准，允许输出 `NO PICK`。

## 典型调用

- “按这个 Skill 帮我从零选一个美国独立站产品。”
- “实物和虚拟产品都可以，先问我你真正需要的条件，再开始筛。”
- “我看到某个趋势正在上涨，帮我判断它到底是不是 DTC 机会。”
- “比较这 4 个产品，不要只看销量，告诉我哪个最值得真实测试。”

## 边界

不负责最终供应商谈判、建站、广告投放或把研究结果当 PMF。选品完成后，应交给供应链 / 产品交付流程，并用真实流量和真实付款继续验证。
