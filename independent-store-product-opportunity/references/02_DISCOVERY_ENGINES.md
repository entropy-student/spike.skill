# Discovery Engines

Discovery 的目标是高召回，不是证明。六个引擎：Behavior/Trend、Problem/Workaround、Review-gap、Transaction-structure、Service-to-Productization、Capability/Adjacency。

## Trend-first 标准流程
Broad behavior → scenes → repeated objects → pain/persona → exact product revalidation → commerce/saturation。

## Problem-first
Repeated pain → workaround → failed reason → current spend → product mechanism。

## Review-gap
Transactions → negative reviews → must keep / fix → underserved segment → product thesis。

## Transaction-structure
Category spend → price bands / concentration / new entrants / review barrier → structural gap。

## Service-productization
Paid human service → repeatable deliverable → automatable core → self-serve offer。
