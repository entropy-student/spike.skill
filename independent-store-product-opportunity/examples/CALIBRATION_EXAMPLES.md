# Calibration Examples

这些示例只演示方法，不代表默认推荐，也不包含任何用户画像。

## Example A — 强交易、弱 DTC 的实物
某配件在 Marketplace 销量很高，但平均售价低、头部集中、同款密集。
结论：Payment Reality 强，但 DTC Wedge / Economics 可能弱；不能因销量直接 Priority Test。

## Example B — 强趋势、弱付款的机会
某生活方式关键词快速上涨，社媒出镜率高，但没有稳定交易或高成本 workaround。
结论：Discovery Signal 强，Payment 仍 UNKNOWN；应先 HOLD 或做真实 WTP/fake-door。

## Example C — 人工服务产品化
某人工服务长期有人付费，交付中大量步骤重复，可被自助工具自动化。
结论：Service-to-Productization 候选成立；下一步验证用户是否接受“无真人”的低价自助版本。
