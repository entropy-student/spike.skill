## 它解决什么问题？

很多人听歌时其实只有两个感觉：

> “好听。”
>
> “不好听。”

但真正难的是继续回答：

- 为什么好听？
- 是旋律好，还是编曲好？
- 为什么副歌听起来特别爽？
- 为什么有的歌词很简单却很高级？
- 为什么有些 AI 歌制作精致，却总觉得“很像 AI”？
- 我自己做的歌到底应该先改哪里？

**Music Quality Radar** 就是为这些问题做的。

它不要求你先学一堆乐理，而是先用普通语言把音乐拆开看。

---

## 七个最重要的判断

| 维度 | 最简单的问题 |
|---|---|
| 🎵 **旋律** | 听完以后，有没有一句留在脑子里？ |
| 🎛️ **编曲** | 什么时候该加、什么时候该减？高潮有没有被托起来？ |
| ✍️ **歌词** | 是真的写出了一个画面，还是只在说“我爱你、我难过”？ |
| 📈 **情绪** | 情绪有没有发展，还是从头到尾一直一个状态？ |
| 🎤 **演唱/演奏** | 像在表达一句话，还是只是在正确地唱音符？ |
| 🎚️ **声音质感** | 清不清楚、挤不挤、舒服不舒服？ |
| ✨ **独特性** | 听十几秒以后，能不能认出“这是它”？ |

## 四级评级

> **B：能听，但普通。**  
> **A：好听，完成度高。**  
> **S：优秀，听完会记住。**  
> **S+：标杆级，这首歌有一种“只能是它”的感觉。**

复杂不等于高级，流行不等于优秀，制作贵也不等于好音乐。

真正重要的是：

> **旋律、编曲、歌词、声音和情绪有没有共同完成同一件事。**

---

## 最快用法

直接把一首歌、音频、歌词或 AI 音乐 Prompt 给 AI，然后说：

```text
按 Music Quality Radar 分析一下。
少用专业术语，告诉我为什么好听/不好听，
旋律、编曲、歌词、情绪分别怎么样，
最大优点和最大问题是什么，最值得怎么改，
最后给 S+ / S / A / B 评级。
```

也可以直接问：

```text
为什么这首歌我听着很高级？
```

```text
这两首歌谁的编曲更好？
```

```text
这段歌词为什么感觉很俗？
```

```text
这首 AI 歌哪里最有“AI味”？
```

## 它不会做什么？

它不会因为一首歌：

- 和弦复杂
- 乐器多
- 高音高
- 播放量大
- 歌词看起来很文艺

就自动说“高级”。

也不会把“我个人不喜欢这种风格”误判成“这首歌做得不好”。

## 当前状态：v0.1

这是一个 **校准版 Skill**。

最好的使用方式不是先相信这套规则，而是拿真实歌曲来测试它：

1. 找你特别喜欢的歌
2. 找你觉得普通的歌
3. 看它的判断是否符合你的真实听感
4. 用反例继续调整 S/A/B 边界

就像 Entertainment Rander 一样，这个 Skill 会在真实案例里越来越准。
