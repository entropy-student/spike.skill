# 闲鱼校准案例（2026-10-03，v2.2）

这是证据边界示例，不是永久选品推荐或平台销量榜。正式项目目录在 [entropy-student/project](https://github.com/entropy-student/project/blob/main/xianyu/docs/FINAL_SKU_CATALOG_2026-10.md)。

旧 v2.0.1 的“6 Confirmed + 44 Probable”与 v2.1 导出的“1 Confirmed + 11 Probable + 49 Watchlist”，均不能作为当前证据真值。

## 有用的发现，仍需正确归属

- 多个会员、预设、标书 Offer 有“想要”，可保留为有价值的 D2 线索；重复想要不证明明确付费意图。
- 2026-07-29 [新华社报道](https://www.xinhuanet.com/tech/20260729/3ba4f5d1aaf044229b890f40ce52f492/c.html)包含上半年平台交易数据与 AI 漫剧教程销售案例。AI教程/课程族的上半年数据为历史 reported D4；漫剧案例只写“半年”，精确起止 UNKNOWN，不能替它补成上半年。两者均不能凭十月读取日改成最近90天成交，更不能确认新增项目文件/Workflow 的 Bundle。
- 标书按次代生成、软件许可、会员、租号是不同 Offer，不能把混合相关推荐统一叫“软件需求”。
- 卖家全店累计卖出不是当前这个 SKU 的销量。商品最低引流价也不是所有规格的售价。

## 边界校准

| 输入 | 合理结论 |
|---|---|
| 4篇免费教程，各有大量收藏和免费求资料 | 免费内容兴趣 D2；付费模板没有自动获得购买意图 |
| 3个独立商品各300想要，无询盘/成交 | D2；可优先补证，不能 D3 |
| 同一付费Offer的3个独立买方询问29元价格及交付 | D3，不要求3个卖家；仍未证明成交 |
| 单卖家自称已售5000，无记录或平台数据 | CLAIM；可定位商品供给 D1，不能 D4 |
| 2024平台成交数据，2026重新打开 | 历史 D4，当前需求未知 |
| 完整“教程+文件”Bundle有可定位近期付款 | 该 Bundle可 D4，无需每个部件各有销售记录 |
| 新原创模板尚无需求证据；权利/路径/交付明确，授权50元7天实验 | 可设计特定 TEST_READY 需求实验；仍 U/D1，不宣称需求已验证 |
| 明确需求但权利或交易路径未知 | 保留需求，相关售卖实验不能 TEST_READY |
| 达预算但仍有未知，平台仅部分访问 | 可停止交付部分目录，列缺口，不声称市场饱和 |

实际行为验证及历史字节核对见 [最终Review记录](../reviews/XIANYU_DEMAND_V2_2_FINAL_REVIEW.md)。已有历史版本保持原貌。
