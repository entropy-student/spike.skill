## E. 学术：信任 / 风险 / 评论

### Trust / Risk / Security / e-WOM Meta-analysis (2024)
https://doi.org/10.1016/j.heliyon.2024.e29714

用途：
- Trust / perceived risk / security / e-WOM 的一般机制。

### Perceived Risk Systematic Review (2024)
https://doi.org/10.1111/ijcs.13067

用途：
- 感知风险与线上购买意图；
- 强调情境和风险类型差异。

### Online Reviews Meta-analysis (2024)
https://doi.org/10.1016/j.dim.2023.100058

用途：
- 评论与购买意图；
- 不把“有评论”机械等同于“有信任”。

## F. 配送 / 退货

### Return Policy Fairness
https://www.sciencedirect.com/science/article/pii/S0969698914000137

用途：
- 退货政策、感知公平、信任和购买意图。

### Free Return / Free Shipping Field Experiment (2025)
https://doi.org/10.1287/msom.2024.0779

用途：
- 免费配送 / 免费退货可能有效，但效果存在异质性；
- 因而归为商业实验规则，而不是所有店强制最佳实践。

## 来源纪律

1. A 级来源用于建立通用骨架；
2. 平台官方文章用于当前实践，不当成普遍因果定论；
3. 单品牌案例只作案例；
4. 行业平均只做方向感，不给单店判刑；
5. 支持证据和反证同时找；
6. 规则必须带适用条件；
7. 时间敏感信息使用前重新联网核验。
