# Spoken Rewrite

这一阶段只改变“怎么说”，不改变“说什么和按什么顺序说”。

## Structural invariants

不可静默修改：Hook 承诺、Takeaway、事实/数字、证据顺序、Payoff、CTA 功能。

## Rewrite rules

- 写给耳朵：主语和动作尽早出现。
- 一句只承担一个主要动作或判断。
- 复杂定语前置太长时拆句。
- 第一次出现的新名词说全，随后才缩写。
- 数字只留听众必须记住的；多个数字优先比较关系而不是连续报数。
- “它、这个、那件事”必须在纯音频中仍能找回指代。
- 抽象名词堆叠改为“谁做了什么，结果怎样”。
- 可以有短暂停顿、补充和自我修正，但不得按模板表演随意。
- 不靠粗口、错别字、网络黑话制造真人感。
- 删除空路标与机械总结。
- 现实资料不能改写成作者亲历。

## Common failure patterns

像 PPT 一样逐条念小标题；每段先下同样结论再重复解释；为了口语塞大量“其实/就是说/然后”；强行反转；句长全部一样；结尾突然上价值。
