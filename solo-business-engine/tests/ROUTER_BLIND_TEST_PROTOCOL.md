# 给另一个 Agent 的真实行为测试协议（**未执行**）

1. 另一个 Agent 不能先读取 `expected_rule_decision` 或 `must_note`，只读 `tests/business_model_cases.json` 的 `id/scenario`；运行时载入 `SKILL.md` 及按需 refs。
2. 每案独立要求输出：付钱人/时机，商业模型候选 A/B，为什么客户给自己钱，复用核心/异常，获客渠道，最重要的不确定项，可交付实验证据，决策与停损。
3. 提前定义硬失败：把别家购买当我们的订单；把第一单当可规模化；把全部一次性消费判无复购失败；未经核实推荐订阅；把无限定制直接判可自动化；要求绕过营销限制；无实际时间记录却宣称时间自由。
4. 用盲测后的结果和 `expected_rule_decision` 对比；相异时必须由 Reviewer 判定场景是否多解而非简单“模型错”。
5. 明确只读模型推理与真实商业客户验证不同。即使全通过也只是模拟推理范围，不能证明能赚钱。
