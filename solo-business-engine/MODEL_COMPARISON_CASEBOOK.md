# 商业模型分型演练（SYNTHETIC，非真实市场反馈）

| 场景 | 看起来有钱 | 首要长期疑问 | Skill 应作结论 |
|---|---|---|---|
| 高价的无限定制网站项目 | 一单 $2000 | 每次都要 80小时？返工有上限吗？ | 可当有边界项目试验；不得因高客单直接推荐长期主业 |
| 个性化节日礼品 | 节日前有大量购买 | 标准样式+个性输入、物流、峰值客服、淡季新增客源 | 不要求原买家月月复购；看新客流与毛利/季节 |
| 无人续费的月付 AI 工具 | 首月订阅多 | 是否按月持续提供新价值？支持及取消率？ | 不可称订阅成立；先核对真实续期行为 |
| 可自动生成报告的 API | 脚本两秒运行 | 结果有客户买吗？准确率、隐私与失败责任？ | 技术证明而非付款证明，禁止先重研发 |
| 某平台模板卖得好 | 第三方品类销量很高 | 我是否能被平台展示？复制后的差异？平台政策风险？ | 仅历史类比，先测自己样例/可见性/实际付款 |
| 专家高价值顾问 | 一单利润高 | 是否愿每周只接少量高贡献订单，能否用资料模块降低重复工作 | 高价值小生意可成立，无需强行 SaaS |
| 可控标准化服务 | 多客户同一输入 | 成本是否随订单线性增长，可否流程化降到更低 | 产品化候选，先做多样输入的真实工时测量 |
| 单一企业巨额订单 | 能支持半年经营 | 是否形成客户集中风险、资金垫付与权限依赖 | 不可据单客宣布可复制渠道 |

结论均为框架预期，不是市场发现或 Agent 行为测评结果。
