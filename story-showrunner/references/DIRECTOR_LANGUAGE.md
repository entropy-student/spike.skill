# Director Language — Candidate v0.1

## Boundary

Director consumes:
- locked script
- KnowledgeCore
- Production SRT
- editorial/visual profiles

Director owns **visual meaning and visual rhythm**, not speech duration.

## Six-layer system

```text
Dramatic Hierarchy
→ Episode/Sequence Visual Strategy
→ Visual Intention
→ Semantic Shot
→ Visual Beat
→ Production-SRT Visual Mapping
```

## Dramatic hierarchy

Use:
`Sequence → Scene → Beat`

Beat = action/reaction/tactic change.

Scene = perceptible story/state turn.

Sequence = larger cumulative movement.

## Visual strategy

Before shot design define:
- primary visual engine
- optional secondary engine
- world/scene system
- 0–2 motifs
- 1–3 dominant visual components
- intensity arc
- image-relation grammar

Example engines:
- ACTION_REACTION
- INVESTIGATION_DISCOVERY
- RELATIONSHIP_DIALOGUE
- PROCESS_TRANSFORMATION
- CONTRAST_COMPARISON
- EVOLVING_METAPHOR
- OBJECT_LED
- ASSOCIATIVE_MONTAGE
- HYBRID

## Visual intention

Every meaningful unit has one primary:
- ORIENT
- FOLLOW_ACTION
- READ_REACTION
- NOTICE_OBJECT
- SHARE_POV
- SEE_CONSEQUENCE
- EXPERIENCE_REVERSAL
- LAND_PAYOFF
- TRACK_METAPHOR_STATE
- COMPARE_STATES
- BUILD_PATTERN
- CLARIFY_MECHANISM

Camera choices come after intention.

## Semantic Shot

One coherent Director strategy.

Locks:
- dramatic refs
- intention
- shot function
- subject priority
- blocking
- framing strategy
- POV strategy
- composition
- eye trace
- visual intensity
- image relation
- visual state
- acceptance

## Visual Beat

Closest planning unit to one generated still.

Split only when image-level meaning changes.

A list in narration does not automatically require montage.

Setup/reveal may split when withholding itself creates payoff.

## Timing

Production SRT is the spoken clock.

Director may:
- cut
- hold
- handoff
- split setup/reveal
- create reaction stills
- choose visual density

Director may not:
- choose TTS speed
- change speech cue duration
- invent chars/s
- do routine post-TTS retiming

If visual meaning truly cannot fit:
`RETURN_TIMING_VISUAL_CONFLICT`

## Editing priority

Use Murch-like priority:
Emotion → Story → Rhythm → Eye trace → 2D plane → 3D continuity.

## Anti-PPT rule

Mechanism visualization preference:
1. story consequence
2. character action/decision
3. prop/world-rule behavior
4. evolving metaphor
5. POV/object/UI
6. montage/contrast
7. explicit diagram last

## Observability

Produce a human-readable Director Shotboard for debug/audit.
It is not a mandatory Owner approval Gate.
