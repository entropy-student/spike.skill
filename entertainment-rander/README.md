## 为什么要有这个 Skill？

娱乐热搜每天都有，但真正能留下来的梗很少。

普通榜单擅长回答：

> **“今天什么最热？”**

Entertainment Rander 更关心：

> **“大家只是看过它，还是已经开始复读、模仿、改写、考古、二创，甚至继续往下编？”**

它不是在做新闻聚合，而是在做一种更接近真实互联网体感的 **娱乐文化筛选**。

它特别适合：

- 每日 / 每周娱乐热梗雷达
- 短视频、图文、封面、选题策划
- 判断一个热点值不值得跟
- 回看历史热梗，区分“曾经很热”和“真正留下来了”
- 建立一套可重复调用的“网感判断系统”

## 四级模型

> **B：大家会说。**  
> **A：大家会模仿。**  
> **S：大家会继续编。**  
> **S+：大家会拿它创造下一代梗。**

| 等级 | 核心状态 | 典型表现 |
|---|---|---|
| **S+** | 梗已经成为互联网母版 / 文化资产 | 新事件还能继续套用它、解释它、借它创造新梗 |
| **S** | 形成持续增殖的内容生态 | 会长出子梗、人物、世界观、考古、混剪、新解释 |
| **A** | 全民参与、强模仿 | 很多人会拍自己的版本，但主要还是复制模板 |
| **B** | 高认知、高复读 | 大家会说，但很少继续创造新东西 |

### 当前校准样本

- **S+**：甄学、明学
- **S**：《花少2》考古、《我的前半生》考古、麦琳 / 麦学、技能五子棋、怀民亦未寝
- **A**：科目三、晚安大小姐、挖呀挖呀挖、恐龙抗狼
- **B**：你真是饿了、栓Q、泰裤辣、尊嘟假嘟

> **重要：热度不是等级。** 一个几十亿播放的跟跳梗可以只是 A；一个数据没那么夸张、但能不断长出新内容的现象反而可能是 S。

## 八个判断维度

Entertainment Rander 会综合判断：

1. **娱乐性** — 第一反应是不是“好玩”“想接梗”
2. **破圈度** — 是否脱离原粉圈 / 原节目传播
3. **持续性** — 是一天热搜，还是能持续数周甚至周期性复活
4. **二创性** — 是否出现改写、混剪、模仿、重构、考古
5. **脱源性** — 离开原始出处后还能不能成立
6. **衍生能力** — 能否长出“某学 / 某宇宙 / 某文学 / 某体系”
7. **创意密度** — 大家是在复制，还是在创造
8. **网感 / 审美** — 纯土味、纯机械跟跳会降级；抽象、反差、语境丰富会加分

其中最重要的一问是：

> **大家是在复制，还是已经开始继续创造？**

这是 **A 与 S** 最关键的分界线。

## 它特别擅长发现

### 📼 考古宇宙
旧综艺、旧电视剧、旧片段突然重新成为公共素材库。

### 🧪 人物学派
一个人物不只贡献一句台词，而是长出“某学”“某文学”“某体系”。

### 🌀 抽象内容体系
有自己的语言、人物、逻辑和世界观，网友可以持续往下编。

### 🎵 魔性内容
BGM / 唱腔 / 表演本身只是入口，真正价值在于能不断出现新玩法。

### 🧬 梗母体
一个源头能持续生出子梗，并在后续完全不同的事件中复活。

## 快速使用

### 1. 扫描最近热梗

```text
按 Entertainment Rander / 娱乐热梗雷达标准，筛选最近一段时间真正值得关注的中文互联网娱乐热梗。
不要新闻，不要只看热搜，也不要仅因为播放量大就判高分。
按 S+ / S / A / B 评级，并说明大家是在“说、模仿、继续编”，还是已经形成可复用的梗母版。
```

### 2. 判断单个梗

```text
“XXX”算 S 级吗？按 Entertainment Rander 的标准判断，并告诉我它为什么是 S / A / B。
```

### 3. 做历史回顾

```text
从 2020–2025 年各挑一些典型娱乐热梗，按 Entertainment Rander 分为 S+ / S / A / B，并解释哪些真正留下来了。
```

## 不要误判这些东西

默认不要因为以下原因就给高等级：

- 明星恋情 / 官宣 / 离婚等新闻本身
- 一次性热搜或口误
- 纯粹严肃、沉重的文化事件
- 单纯爆款歌曲但没有梗化
- 全民跟跳但没有新的内容增殖
- 人人都会说、但本质只是口头禅
- 单纯“数据特别大”
