# Meme Music Router（热梗音乐路由器）

> 在现有热点、音乐趋势与音乐质量 Skill 的判断基础上，专门负责：**把近期高等级热点路由到最合适的音乐化方式，并优先输出 S+ / S / A+ 高潜力方案。**

## 它解决什么问题？

很多“热点 × 音乐”内容的问题不是没有流量，而是：

- 热点够热，但配歌很硬；
- 歌很热门，但和人物没有真正关系；
- 为了完成“找热歌”步骤，反而牺牲了梗本身；
- 只停留在“这个 BGM 挺合适”；
- 明明原创更适合，却硬蹭现成歌；
- 最后列了一堆 A / B 方案，真正值得做的反而不突出。

这个 Skill 的目标是：

> **让 Entertainment Rander 判断热点值不值得玩，让 Music Trend Radar 判断歌是不是真的热，让 Music Quality Radar 判断最终音乐好不好；Meme Music Router 只负责把这些结果组合成漂亮的创意。**

---

## 默认时效

当前项目默认只看近期：

1. **今天 / 过去 24 小时**
2. **近 3 天**
3. **最多近 7 天，但必须仍在持续发酵**

过去很火但现在已经退潮的内容，不进入默认近期选题库。

---

## 第一关：热点等级先过门槛

默认最终选题模式：

```text
Entertainment Rander S+ → Pass
Entertainment Rander S  → Pass
Entertainment Rander A  → 默认不进入主制作池
Entertainment Rander B  → Reject
```

所以一个 A 级热点即使音乐创意很好，也不会在默认榜单里越级压过 S / S+ 热点。

---

## 四条路由全部保留

```text
热点 / 梗
   ↓
它本身是否自带音乐？
   ├─ 是 → Route A：保留原生音乐，寻找最绝的场景 / 角色
   │
   └─ 否
       ↓
近期热歌有没有天然匹配？
   ├─ 有 → Route B：近期热歌再叙事
   │
   └─ 否
       ↓
经典高认知歌曲有没有天然匹配？
   ├─ 有 → Route C：经典歌曲再叙事
   │
   └─ 否 → Route D：跳过找歌，直接原创音乐化
```

**不要为了完成“找热歌”而硬配。**

Route D 原创不是降级方案；如果原创更能把梗玩漂亮，就应该直接原创。

## 与现有 Skills 的边界

### Entertainment Rander
负责：

- 热点 / 梗本身是什么等级；
- 是否达到 S / S+；
- 是否有足够娱乐性、破圈与二创增殖。

### Music Trend Radar
负责：

- 哪些歌近期真实热门；
- 哪些在爆 / 翻红；
- Rank / Tier / Confidence。

### Music Quality Radar
负责：

- 最终音乐到底好不好听；
- 旋律、编曲、歌词、情绪推进、演唱、制作与独特性；
- 最值得怎么修改。

### Meme Music Router
只负责：

- Route A / B / C / D；
- 单人物化；
- 身份 / 剧情闭环；
- “非这首不可”；
- 创意扩展；
- 高等级候选排序。

> **前三个 Skill 是裁判，Router 是导演。**

## 当前创作偏好

### 高能量优先

其他条件相近时：

**欢快 / 热情 / 强律动** ＞ **燃 / 爽 / 戏剧性** ＞ 中速 ＞ 慢歌 ＞ 苦情慢歌。

### 单人物优先

默认：

> **一个热点人物 × 一个角色 / 场景 × 一种音乐路线。**

多人轮唱不是禁止，但默认降级。

### 关系闭环优先

最强创意不是“情绪像”，而是：

```text
现实人物
→ 当前热点 / 当前音乐
→ 经典角色 / 旧身份 / 名场面
→ 音乐重新解释角色
```

固定 S 级锚点：

> **唐艺昕 × 祺贵人 / 滴血认亲 ×「你嘴巴多毒我才不在乎」 = S。**

---

## B / A / A+ / S / S+

| 等级 | 一句话 | 用户反应 |
|---|---|---|
| **B** | 能配 | “嗯，可以这么配。” |
| **A** | 配得巧 | “这个搭配挺巧。” |
| **A+** | 预备 S | “已经很接近了，再补一层就绝。” |
| **S** | 就应该这么配 | “卧槽，这首歌 / 这个玩法就该给 TA。” |
| **S+** | 形成新玩法 | “原来还能这么玩，我也想找一个。” |

### A+ 的意义

A+ 不是“普通 A 稍好一点”。

它表示：

> **热点起点已经够强、创意已经接近 S，而且有明确升级路径，值得继续多想几版。**

例如：

- 只差一个更强身份闭环；
- 只差找到真正“非这首不可”的歌；
- 借歌不够漂亮，但切换原创可能直接升 S；
- 已有好想法，但名场面 / Hook 还不够强。

---

## 默认最终输出：只看 S+ / S / A+

用户最终调用时，默认主输出只保留：

- **S+**
- **S**
- **A+**

普通 A / B 默认隐藏，只在：

- 边界校准；
- 失败分析；
- 用户明确要求全量候选池；

时展示。

### 不机械凑数

建议主动搜索：

- S+：0–3 个，没有就明确没有；
- S：尽量 3–8 个高质量不同打法；
- A+：尽量 3–10 个，并说明如何升级到 S。

**宁可少给，也不把普通 A 抬成 A+ / S。**

---

## 高等级候选要多想创意

通过第一关的热点，不要在第一个“能用”的配法就停止。

主动检查：

1. 最值得使用的核心人物是谁？
2. 是否存在经典角色 / 旧身份 / 名场面？
3. 梗是否本身自带音乐？
4. 有没有天然近期热歌？
5. 经典歌是否反而更强？
6. 没有好歌时，原创是否更漂亮？
7. 同一热点能否给出 2–3 个真正不同的高等级打法？
8. A+ 具体缺什么才能升 S？

---

## “非这首不可”测试

针对借歌方案问：

> **把这首歌换成另外三首类似歌曲，创意是否几乎一样成立？**

- 随便换都成立 → 多为 B / A；
- 换掉后最关键的巧妙关系消失 → 接近 S。

S+ 更严格：它意味着作品开始生成下一代作品，而不是单纯“比 S 更好”。

```text
    ↓
近期 S / S+ 热点池
    ↓
Meme Music Router
    ↓

    ↓
Music Trend Radar
    ↓

    ↓
Music Quality Radar
    ↓
把高等级创意真正做好听
    ↓
Music Prompt Generator
    ↓
当前仍需真实 Suno / 音乐模型生成校准
```

## 一句话调用

```text
按 Meme Music Router 跑近期选题。
先用 Entertainment Rander 只保留近期 S / S+ 热点，
再按 Route A/B/C/D 多想几个不同音乐化方案；
歌曲热度只服从 Music Trend Radar，音乐质量只服从 Music Quality Radar；
默认只输出 S+ / S / 有明确升级潜力的 A+，普通 A/B 不要进入主榜。
```
