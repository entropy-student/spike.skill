# Language Flexibility Rules（输出语言灵活性规则）

本规则用于 `meme-music-router` 的所有最终呈现内容，包括但不限于：

- 梗图文字；
- 图片中的短句 / 标题；
- 台词 / 口播；
- 原创歌词；
- 改编歌词；
- Hook；
- 标题；
- 其他最终可见 / 可听内容。

## 1. 核心原则

最终呈现语言 **不固定为中文**。

Router 应根据：

- 原梗的语言环境；
- 本期选中的具体二创版本；
- 人物 / 角色身份；
- 传播平台与受众；
- 笑点、反差、节奏、押韵与情绪效果；
- 哪种语言最能让梗成立；

灵活选择：

- 中文；
- 英文；
- 中英混合；
- 方言 / 口语化表达；
- 其他更适合当前梗的语言形式。

> **目标不是“默认用中文”，而是“哪种语言更能把梗玩漂亮，就用哪种”。**

---

## 2. 优先级

当语言选择与风格选择发生冲突时，按以下顺序处理：

1. 保留原梗识别度；
2. 保留本期选中二创版本的识别度；
3. 选择最能强化笑点 / 反差 / 情绪 / 传播性的语言；
4. 最后再优化文案漂亮程度与统一风格。

禁止为了“统一中文”破坏梗，也禁止为了“国际化”强行塞英文。

---

## 3. 图片 / 梗图

图片中的文字不是必须中文。

如果：

- 原梗本身依赖英文；
- 二创版本来自其他语言文化语境；
- 中英混合更有网感；
- 不写文字反而更强；

都允许直接采用最有效的方案。

语言选择必须服务于：

> **Source fidelity → Selected derivative fidelity → Meme effect**

而不是为了形式统一。

---

## 4. 歌词 / Hook / 台词

原创或改编歌曲可以使用中文、英文、中英混合、方言、其他语言点缀，或根据梗的具体语境选择更合适的表达。

但语言变化必须有明确作用，例如：

- 提升 Hook 记忆点；
- 强化角色身份；
- 强化二创版本的文化语境；
- 让押韵 / 节奏更自然；
- 形成更强反差或笑点。

禁止只为了“听起来国际化”随机加入外语。

---

## 5. 与上游 Skill 的边界

本规则只决定 **最终呈现语言如何选择**，不重新定义：

- 什么是好梗；
- 什么是热歌；
- 什么是好音乐。

需要专业判断时仍按 Router 规则现场调用对应上游 Skill。

---

## 6. 发送前检查

```text
当前输出是否被默认语言习惯绑架？
↓
原梗 / 二创版本是否有更自然的语言选择？
↓
混合语言是否真的增强梗，而不是装饰？
↓
最终语言是否让用户更快理解、更想传播？
↓
交付
```

> **Language serves the meme. The meme does not serve the language.**
