# Meme Image Reference-First Rules（梗图参考优先规则）

本规则用于 Meme Music Router 在选题确认后的梗图 / 配图阶段。

## 核心原则

> **先找到梗的真实来源，再生成。先“像梗本身”，再做风格化。**

梗图的核心不是凭空创造一个“符合概念的人物”，而是尽量保留用户已经认识的真实视觉记忆。

---

## 1. 生图前必须先溯源

如果选题包含明确的：

- 真人 / 明星；
- 影视角色；
- 综艺人物；
- 动物；
- 商品 / 道具 / 物件；
- 经典名场面；
- 特定造型、服装、妆容或动作；

在生成梗图前，先查找其真实来源与近期 / 经典参考图。

默认至少确认：

1. 主体是谁 / 是什么；
2. 最具辨识度的发型、妆容、服装、配饰；
3. 经典表情 / 动作；
4. 原梗最典型的场景；
5. 关键道具或环境；
6. 哪些视觉元素一旦改掉，就会让熟悉这个梗的人觉得“这不是 TA / 这不是这个梗”。

---

## 2. 参考图是视觉锚点，不是装饰

找到的来源人物 / 事物应作为后续生图的**视觉参考依据**。

优先保留：

- 脸部与年龄气质；
- 发型；
- 妆容；
- 经典服装 / 配饰；
- 体态；
- 经典表情；
- 名场面构图；
- 场景与关键道具。

可以改变：

- 画面风格；
- 灯光；
- 构图强弱；
- 背景简化；
- 色彩；
- 海报 / 表情包 / 截图感；
- 为了强化梗而做的适度夸张。

但风格化不能覆盖原角色识别度。

---

## 3. 默认顺序

```text
确认选题
↓
识别梗的真实来源人物 / 角色 / 物件 / 名场面
↓
搜索 2–5 张有代表性的参考图
↓
提取不可丢失的视觉特征
↓
确定本期梗图的视觉笑点 / 反差
↓
再生成图片
```

如果用户已经提供了明确参考图，优先使用用户提供的图，不需要重复凭空设计主体。

---

## 4. 禁止“概念替身”

以下情况默认视为失败：

- 选题是具体影视角色，却生成一个只符合角色性格的陌生人；
- 选题是具体明星，却只生成“同年龄 / 同气质的帅哥美女”；
- 角色有经典妆造，却擅自换成更时髦但完全不属于原角色的造型；
- 原梗依赖特定场景 / 道具，却只保留一句文字；
- 为了“高级感”把原梗最具辨识度的俗、土、夸张、年代感元素全部洗掉。

> **梗图不是角色再设计比赛。用户第一眼认不出梗，视觉再漂亮也不合格。**

---

## 5. 薛甄珠反例校准

错误做法：

> 只根据“强势、护女、富贵感的中年妈妈”自由设计成墨镜、豹纹、女王式造型。

问题：

- 概念上像“强势妈妈”；
- 但不像《我的前半生》里的薛甄珠；
- 丢失角色已有的视觉记忆；
- 熟悉梗的人需要重新理解，破坏 1–3 秒识别。

正确做法：

先查薛甄珠经典剧照 / 梗图，提取例如：

- 复古短卷发；
- 红唇；
- 大项链 / 珍珠等明显饰品；
- 鲜艳、花色、富贵感但带生活气的服装；
- 强烈表情与动作；
- 《我的前半生》具体办公室 / 手撕凌玲等名场面语境。

之后才决定做成电视剧截图感、表情包、海报或其他视觉风格。

---

## 6. 当参考资料不足时

如果无法确认真实造型：

- 不要装作已经知道；
- 不要自行补大量具体视觉细节；
- 优先继续搜索可靠参考；
- 若仍不足，生成时减少对身份细节的自由创造，并明确把重点放在已确认元素上。

---

## 7. 默认生图 Brief 新增字段

```yaml
meme_image_reference:
  source_entity:
  source_type: person | character | object | scene | other
  source_work_or_origin:
  reference_images_found: true | false
  iconic_visual_traits:
    -
  iconic_scene_traits:
    -
  must_preserve:
    -
  may_stylize:
    -
  forbidden_invention:
    -
  recognition_target: recognizable_in_1_3_seconds
```

---

## 8. 图片文字语言不固定为中文

如果图片需要标题、台词、短句或其他文字，其语言遵循：

`references/LANGUAGE_FLEXIBILITY_RULES.md`

允许根据原梗、本期二创版本和传播效果选择：

- 中文；
- 英文；
- 中英混合；
- 方言 / 口语；
- 其他更自然的语言形式；
- 或者完全不放文字。

> **图片文字的目标是强化梗，不是满足“必须中文”的形式要求。**

同时禁止为了显得国际化而无意义加入外语。

---

## 9. 最终判定

生成前先问自己：

> **如果把文字全部删掉，一个熟悉这个梗的人还能不能基本认出人物 / 角色 / 名场面？**

- 能 → 可以继续风格化；
- 不能 → 先修正人物、妆造、场景或关键道具，再谈美术风格。

如果需要文字，再继续问：

> **当前语言是不是最能让这个梗成立的语言？**

最终目标：

> **Reference first. Recognition first. Style second. Language serves the meme.**
