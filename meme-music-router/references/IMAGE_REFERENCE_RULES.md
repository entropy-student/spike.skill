# Meme Image Reference-First Rules（梗图参考优先规则）

本规则用于 Meme Music Router 的图片 / 梗图节点，并服从：

`references/MEME_AMPLIFICATION_RULES.md`

核心：

> **图片是梗的视觉放大器，不是重新选题。**

---

## 1. 先锁梗，再生图

生图前必须已有：

- `meme_core`
- 原人物 / 原场景
- 本期选中的具体二创版本
- 最需要放大的视觉笑点

如果这些没有明确，不生成。

最终图片必须同时保留：

```text
原梗识别度
+
选中二创版本识别度
```

例如：

```text
薛甄珠手撕凌玲
+
印度电影歌舞版
```

不能只剩“薛甄珠办公室剧照”，也不能只剩“印度风女人”。

---

## 2. 具体人物 / 场景先找真实参考

如果涉及真人、影视角色、综艺人物、具体物件或经典名场面：

1. 先找 2–5 张代表性参考图；
2. 提取最少量、最高识别度特征；
3. 用参考图承担身份细节，不把所有细节重复塞进 Prompt。

优先保留：脸 / 年龄气质、发型、妆容、经典服装配饰、表情动作、名场面环境与关键道具。

> **Reference first. Recognition first. Derivative fidelity second. Style last.**

---

## 3. 生图 Prompt：硬上限 200 字

最终发送给生图模型的正文：

- **硬上限 200 个中文字符左右**；
- 推荐 80–160 字；
- 不计算参考图列表、尺寸、比例等工具参数；
- 不写长篇背景故事；
- 不堆十几条 negative prompt；
- 能靠参考图表达的身份细节，不重复写。

推荐结构只保留 5 件事：

```text
主体是谁
+ 原梗场景
+ 本期二创玩法
+ 2–4 个必须保留特征
+ 最重要的禁止项
```

### 薛甄珠示例

> 4:3梗图。还原《我的前半生》薛甄珠短卷发、红唇、珍珠项链，冲进办公室找凌玲；演绎成印度电影歌舞版，动作夸张、群像惊愕、色彩高能。人物必须像原角色，不改成印度女性；无字无水印。

---

## 4. 禁止概念替身

以下默认失败：

- 具体角色 → 生成“气质相似的陌生人”；
- 经典造型 → 被更时尚的新造型覆盖；
- 名场面 → 只剩一句文字；
- 选中二创版本 → 只剩泛化风格标签；
- 为了高级感洗掉梗原本的俗、土、夸张、年代感。

---

## 5. 语言

图片文字遵循：

`references/LANGUAGE_FLEXIBILITY_RULES.md`

可以中文、英文、混合、方言、其他语言或完全无字。

语言只服务于梗。

---

## 6. 最终检查

生成前依次问：

1. 去掉文字，还能认出原人物 / 原场景吗？
2. 能看出本期选中的二创版本吗？
3. 这张图是否让原梗更有趣，而不只是更漂亮？
4. Prompt 是否 ≤200 字？

全部通过再生成。
