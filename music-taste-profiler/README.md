# Music Taste Profiler（音乐口味画像）

> 从用户授权的歌单和“我喜欢”里，自动分析：**你到底喜欢什么音乐，以及为什么。**

它不是简单统计“你听了多少首流行歌”，而是把用户的真实收藏转换成一份容易看懂的音乐审美画像。

## 它能做什么

输入可以来自：

- 网易云音乐
- QQ 音乐
- 酷狗音乐
- 汽水音乐
- 用户导出的歌单
- 手动提供的歌曲列表

输出尽量不用专业术语，而是直接告诉用户：

> 你偏爱强旋律而不是强节奏。  
> 你喜欢温柔、忧郁但不绝望的情绪。  
> 你更容易被清亮、年轻的人声打动。  
> 你喜欢“前面克制、后面释放”的歌曲。  
> 你不太喜欢从头到尾都很满、只靠节奏炸场的歌。

## 核心流程

```text
用户授权 / 提供歌单
        ↓
读取“我喜欢”与个人歌单
        ↓
去重、整理歌曲与歌手
        ↓
找出反复出现的音乐特征
        ↓
调用 Music Quality Radar 分析代表歌曲
        ↓
生成用户的音乐审美画像
```

## 支持思路

数据读取层优先参考开源项目 [`guohuiyuan/music-lib`](https://github.com/guohuiyuan/music-lib)：

- 网易云：个人歌单 ✅ / 扫码登录 ✅
- QQ 音乐：个人歌单 ✅ / QQ、微信扫码登录 ✅
- 酷狗：个人歌单 ✅ / 扫码登录 ✅
- 汽水音乐：个人歌单 ✅ / 扫码登录目前不稳定

> 注意：汽水音乐当前更适合由用户自行提供已有登录态，不应把不稳定扫码流程包装成正式能力。

画像分析层参考 [`MiniMax-AI/skills`](https://github.com/MiniMax-AI/skills) 中 `minimax-music-playlist` 的 taste profile 思路，但本 Skill 只保留“分析口味”部分，并与本仓库的 [Music Quality Radar](../music-quality-radar/) 联动。

## 输出会看什么

主要看这些：

| 维度 | 用户看到的结果 |
|---|---|
| 曲风 | 你最常听哪些类型 |
| 情绪 | 你偏爱温柔、忧郁、热烈还是治愈 |
| 旋律 / 节奏 | 你更吃旋律还是更吃律动 |
| 人声 | 偏男声、女声、清亮、低沉、气声等 |
| 语言 | 华语、日语、英语、韩语等 |
| 编曲偏好 | 喜欢简单留白，还是层层堆叠 |
| 歌词偏好 | 喜欢故事感、画面感、直白还是抽象 |
| 熟悉度 | 更爱经典老歌，还是持续尝鲜 |
| 代表歌手 | 哪些歌手最能代表你的口味 |
| 核心审美 | 最后用 3–6 句话总结“你为什么会喜欢这些歌” |

## 最重要的原则

### 1. 喜欢 ≠ 质量高

用户喜欢一首歌，不代表它一定是 S 级作品。

所以本 Skill 负责：

> **你喜欢什么？**

而 [Music Quality Radar](../music-quality-radar/) 负责：

> **这首歌本身为什么做得好 / 普通？**

两者结合后，才能回答：

> **为什么“这类好歌”特别容易打中你？**

### 2. 不假装精确

如果只有十几首歌，不输出“你 37.4% 喜欢某风格”这种假精确。

数据越少，结论越保守：

- 10–30 首：初步画像
- 30–100 首：可用画像
- 100–300 首：较稳定
- 300+ 首：高置信度

### 3. 隐私优先

- 只在用户明确授权后读取个人歌单
- Cookie / Token 不写进聊天记录和报告
- 默认只展示聚合结果，不公开完整听歌历史
- 不需要的字段不要保存
- 用户撤回授权后，应停止继续读取

## 最快调用

```text
调用 Music Taste Profiler，分析我的音乐口味。
优先读取我授权的网易云 / QQ 音乐 / 酷狗 / 汽水音乐个人歌单和“我喜欢”。
最后不要堆专业术语，用普通话告诉我：
1. 我最喜欢什么类型
2. 我最吃哪种旋律、情绪、人声和编曲
3. 我为什么会喜欢这些歌
4. 哪些歌曲最能代表我的口味
5. 我的音乐审美还有哪些隐藏特点
如果数据不足，请明确说明置信度。
```

## 与 Music Quality Radar 联动

默认从用户收藏中挑选约 5–10 首最有代表性的歌，再调用 Music Quality Radar 做解释。

这样最终不只是：

> “你喜欢 J-pop。”

而是更接近：

> “你喜欢的并不是所有 J-pop，而是其中旋律线清晰、情绪先克制后释放、女声偏清亮、编曲有空间感的那一支。”

这才是这个 Skill 真正想得到的结果。
